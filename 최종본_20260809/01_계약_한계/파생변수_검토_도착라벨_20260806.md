## 초안 → 판정

| 파생(초안) | 정의 | 판정 | 이유 |
|---|---|---|---|
| 여유충전기 | max(가용대수−1, 0) | **EXCLUDE** | 가짜상관 아님 · **완전 중복**. 필터 때문에 `여유 = 가용대수 − 1` (상관 1.0) |
| ETA보정여부 | `eta_is_proxy` | **EXCLUDE (학습입력)** | 쿼터로 끊긴 충전소 묶음의 **선택편향**. 보정소가 충전기 더 많음(평균 ~4.5 vs ~2.7) → 성공률이 더 높아 보임. 셔플 시 AUC≈0.50. **평가 층화·리포트용만** |
| 경과연령×ETA | min(age,60)×ETA구간 | **EXCLUDE** | AUC≈0.51 · 지금 데이터에서 근거 부족 |
| 가용비율 | 가용/전체 | **HOLD** | 메커니즘은 가능하나 이번 샘플에서 약함 · 가용대수와 ablation 후에만 |
| 상태오래됨 / 미관측여부 | age≥15 · UNOBSERVED | **HOLD** | 게이트로는 의미 있음 · 학습피처는 **시점 맞는 패널**에서만 재검증. 라벨행에 미관측이 거의 없음 |
| 단수충전기 | `total_chargers == 1` | **RETAIN** | 도메인 실패위험과 방향 일치 (단수 도착가용 ↓) |
| ETA구간 | 0–10 / 10–20 / 20–40 / 40+분 | **RETAIN (약한 신호)** | 멀수록 약간 깨짐은 진짜이나 persistence가 커서 효과 작음 · **horizon·거리와 한 묶음** → 셋 중 **하나만** |
| horizon / 거리 | 기존·부수 | ETA구간과 **택1** | 동시에 넣지 말 것 |
