# 프로젝트 문서

| 폴더 | 내용 |
|---|---|
| `requirements/` | 요구사항 및 기능정의서 (기획서 원본 포함) |
| `architecture/` | 시스템 구성도, 아키텍처 결정 기록 |
| `api/` | 백엔드 API 명세 (프론트엔드와 합의된 스펙) |
| `data/` | 공공데이터·외부 API 설명 (엔드포인트, 파라미터, 코드표) |
| `database/` | ERD, 테이블 정의서 |
| `meetings/` | 회의록 (파일명: `YYYY-MM-DD-주제.md`) |
| `troubleshooting/` | 오류 및 해결 기록 (외부 API 장애 이력 포함) |

## 현재 문서

- `data/kakao-local-api.md` — 카카오 로컬 API 카테고리 코드표와 활용 계획
- 외부 API 엔드포인트·키 관리 정보는 `apps/data-pipeline/AGENTS.md`의 표 참고
