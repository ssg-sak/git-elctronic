## 2. 상대별 — 무엇을 · 어떻게

### 2.1 DA➁ (모델·평가·서빙) — **가장 많이**

| 공유할 것 | 경로·문서 |
|---|---|
| D1 스냅샷 | `evaluation/results/datasets/station_feature_snapshot_latest.*` |
| 샘플 | `.../handoff_to_model/` |
| 피처·스키마 | [`피처_카탈로그.md`](../data/스키마/피처_카탈로그.md) · [`데이터셋_명세.md`](../data/스키마/데이터셋_명세.md) |
| 핸드오프 장 | [`팀공유_핸드오프_①to②_*.md`](../팀공유/팀공유_핸드오프_①to②_20260720.md) |
| 관측≠가용 | [`학습가이드_관측과가용.md`](../data/가이드/학습가이드_관측과가용.md) |
| 이용강도(선택) | `station_history_features_latest.csv` — **점수 넣기 전 합의** |
| 공용 후보 | `recommend_public_default` · [`이용제한_필터.md`](../data/가이드/이용제한_필터.md) |

**반드시 합의할 것**
- D1 컬럼 추가·삭제·의미 변경  
- 점수 가중치 (`AGENTS.md` vs 요구사항 §9.1) — **②가 구현, ①은 입력만**  
- 이용강도·제한 플래그를 점수에 넣을지  
- D3 라벨 정의 (AIR-002)  

**①이 안 하는 것 (②에게 넘김)**  
규칙 점수 · 실패위험 등급 · 추천 이유 문장 · ML 학습  

**톡 예시**
```text
[①→②] D1 갱신했습니다.
as_of: (시각)
경로: .../station_feature_snapshot_latest.csv
변경: access_restricted / recommend_public_default 추가
명세: docs/data/스키마/피처_카탈로그.md F15–F17
샘플: handoff_to_model/
점수 반영은 합의 후 부탁합니다.
```

### 2.2 데이터 수집 담당

| 공유할 것 | 내용 |
|---|---|
| EvCharger 호출량 | 오늘 콜 수 · [`KPI_보고서`](../data/운영/KPI_보고서.md) K2 |
| 경계 | ① = SANDBOX status 루프 · **`collection/`·`extracted/` 무단 덮어쓰기 금지** |
| 키 | 같은 `DATA_GO_KR_KEY` — 일 1,000 공유 |
| 이관 | SANDBOX → 공식 스케줄 옮길 때 **사전 합의** |

**즉시 연락**
- 한도 임박 (≥800)  
- 403/키 동기화 의  
- 누가 `extracted/`를 갱신할지

### 2.3 백엔드

| 공유할 것 | 내용 |
|---|---|
| 추천 입력 스키마 | D1 컬럼 · null 정책 · mock 플래그 |
| `eta_minutes` | ①은 **빈 컬럼만** — 값은 TMAP/백엔드 |
| API 계약 | [`API_계약.md`](../API_계약.md) 변경 시 ②·백엔드와 함께 |
| 키 | 프론트 노출 금지 · `.env` / 서버만 (NFR-006) |

**합의 시점**  
응답 JSON에 새 필드(신뢰도·목·이용제한) 넣을 때.

### 2.4 프론트엔드

| 공유할 것 | 화면 연결 |
|---|---|
| `reliability_grade_effective` | 최신성 경고 |

| `recommend_public_default` | 기본 “공용만” 필터 |
| `name_suggests_residential` | 선택적 주의 문구 |
| 가용 숫자 | **관측 가용** vs 전역 대수비 — [`가용률_수치기준`](../data/운영/가용률_수치기준.md) |

직접 UI 코드는 안 고치고, **필드 의미·표시 권장**만 문서/톡으로.
