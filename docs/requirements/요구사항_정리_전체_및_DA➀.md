## 0. 두 문서 관계

| | 종합 요구사항 정의서 v1.0 | 사용자 요구사항 정의서 (docx/SFR) |
|---|---|---|
| **분량** | 전체 (BR·FR·DR·AIR·UIR·IFR·NFR·화면·테스트·인수) | SFR-001~024 기능표 |
| **용도** | 프로젝트 범위·데이터·AI·검수 정본 | 업무 배정·기능 검수 표 |

| **겹침** | SFR ≈ 종합본의 FR + 일부 DR/NFR | 종합본이 상위 집합 |

## 1. 전체 내용 요약 (종합본 기준)

### 1.1 한 줄 목표

> 가까운 충전소가 아니라, **도착했을 때 충전할 가능성이 높은** 충전소를 추천한다.

### 1.2 MVP에 들어가는 것 (Must)

위치·지도·상태·최신성·ETA·규칙 점수·실패 위험·추천 이유·이력 저장·목/실 구분·API 장애 시 기본 추천.

### 1.3 MVP에서 안 하는 것 (Won’t)

예약·결제·원격제어·차량 연동·전국·실시간 주차 **보장**.

### 1.4 확장 (Could / AIR 향후)

도착 시 가용 ML 예측 · 대기시간 · 개인화 · Ranker 등.

### 1.5 CBD 컴포넌트 (①이 닿는 것)

| ID | 이름 | ① |
|---|---|---|
| COM-02 | 충전소 데이터 수집 | 수집과 협업 · SANDBOX status |
| COM-03 | 교통 | UTIC 돌발 · 소통 미완 |
| COM-05 | 주차 | 조인·플래그 · 실API 대기 |
| COM-06 | 날씨 | 추출·격자 |
| COM-07 | 주변시설 | Tour/산책 조인 |
| COM-08 | 전처리 | **주 책임** |
| COM-09 | 특성 생성 | **주 책임** (점수 제외) |
| COM-16 | 이력 저장 | status 시계열·패널 |
| COM-10~12 | 점수·위험·추천 | **②** |
| COM-01,13~15 | 위치·지도·비교·관리 | 프론트·백엔드 |

### 1.6 데이터 (§8)

| 데이터 | MVP | ① 현황 한 줄 |
|---|---|---|
| 충전소 정보 | 사용 | 실추출·마스터 |
| 충전기 상태 | 사용 (5~10분) | **10분 루프 가동** |
| 교통 소통 | 사용 | 대구 API 장애 · mock만 |
| 돌발 | 사용 | **UTIC 실** |
| 주차 기본 | 사용 | mock 보관 · D1 거리 null |
| 주차 혼잡 | **목** | 요구사항과 동일 (mock 허용) |
| 날씨·Tour·산책 | 사용 | 추출·조인 있음 |

### 1.7 파생변수 (§8.1) ↔ ① 피처

| 요구사항 변수 | ① 대응 |
|---|---|
| available_charger_count | `available_count` |
| total_charger_count | `total_chargers` |
| available_ratio | `availability_ratio_observed` |
| status_age_minutes | `status_age_minutes` + observation_* |
| eta_minutes | 컬럼 예약 · 값 null |
| data_reliability_score | `reliability_grade*` |
| operation_available | `is_operating_now` |
| incident / parking / weather / historical | 부분 (돌발 거리 · 주차 null · 격자 · D2 시 과거율) |

### 1.8 점수 가중치 — 문서 간 차이 (주의)

| 출처 | 식 |
|---|---|
| **루트 `AGENTS.md` (팀 공통)** | 가용 40 · 신뢰 20 · 이동 15 · 대기 15 · 주차·운영·편의 10 |
| **종합 요구사항 §9.1** | 가용비율 30 · 대수안정 15 · 최신성 15 · ETA 15 · 과거가용 10 · 주차 5 · 운영 5 · 교통날씨 5 |

→ 점수 구현은 **②**. ①은 입력만. 팀에서 AGENTS vs §9.1 **어느 쪽을 정본으로 할지** 합의 필요.

### 1.9 위험도 등급 차이

| 출처 | 등급 |
|---|---|
| `AGENTS.md` | 낮음 / 보통 / **높음** (3) |
| SFR-008 · FR-014 | 낮음 / 보통 / 높음 / **매우 높음** (4) |

→ **②·프론트** 합의 항목. ① 문서만으로는 닫지 않음.
