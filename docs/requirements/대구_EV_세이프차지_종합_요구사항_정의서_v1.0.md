# 1. 프로젝트 개요

## 1.1 추진 배경

기존 전기차 충전소 서비스는 사용자의 현재 위치에서 가장 가까운 충전소 또는 현재 사용 가능한 충전소를 주로 안내한다. 그러나 사용자가 충전소까지 이동하는 동안 다른 차량이 충전기를 점유하거나, 충전기 상태정보가 오래되어 실제 상태와 다르거나, 교통 정체와 주차 혼잡으로 인해 충전에 실패할 수 있다.

본 프로젝트는 단순한 거리순 안내를 넘어 다음 질문에 답하는 것을 목표로 한다.

> “지금 가장 가까운 충전소는 어디인가?”가 아니라  
> “내가 실제로 도착했을 때 가장 높은 확률로 충전할 수 있는 충전소는 어디인가?”

## 1.2 핵심 목표

사용자의 현재 위치와 충전 조건을 입력받아 대구광역시 내 충전소별 예상 도착시간, 현재 충전기 상태, 상태정보 최신성, 충전기 수, 교통 상황, 주차정보, 날씨 및 과거 상태를 분석하고, 도착 시 실제 충전 성공 가능성이 높은 충전소를 우선 추천한다.

## 1.3 세부 목표

1. 실시간 충전기 상태와 상태 갱신시각을 수집한다.
2. 교통 상황을 반영해 충전소별 예상 도착시간을 계산한다.
3. 충전기 수, 사용 가능 수, 고장·점검 여부를 분석한다.
4. 주차장 혼잡도와 진입 가능성을 반영한다.
5. 날씨와 시간대에 따른 충전 수요 변화를 고려한다.
6. 충전 실패 위험도와 추천 이유를 사용자에게 제공한다.
7. 충전 중 이용 가능한 주변 관광지·산책로·편의시설을 안내한다.
8. 향후 머신러닝 예측모델을 개발할 수 있도록 상태 이력을 저장한다.

# 2. 서비스 범위

## 2.1 MVP 범위

- 사용자 현재 위치 또는 주소 입력
- 대구광역시 충전소 지도 표시
- 충전소별 거리와 예상 도착시간 계산
- 충전기별 현재 상태 표시
- 상태정보 갱신 후 경과시간 표시
- 현재 사용 가능한 충전기 수 계산
- 데이터 신뢰도 계산
- 규칙 기반 사용 가능성 점수 산출
- 충전 실패 위험도 표시
- 추천 충전소 순위와 추천 이유 제공
- 충전소 상세 조회 및 비교
- 주차정보와 목데이터 여부 표시
- 관광지·산책로·주변시설 안내
- 충전기 상태 이력 저장
- 외부 API 장애 시 대체 처리

## 2.2 향후 확장 범위

- 도착 시점 사용 가능 여부 머신러닝 예측
- 충전 대기시간 예측
- 개인별 추천 가중치 학습
- 차량별 충전 규격 자동 설정
- 충전 종료 예상 차량 추정
- 충전소 혼잡도 예측
- 즐겨찾기 및 알림
- 사용자 제보 및 충전 실패 이력
- 대구 이외 지역 확장

## 2.3 제외 범위

- 충전기 예약
- 충전 요금 결제
- 충전기 원격 제어
- 차량 배터리 직접 연동
- 민간 충전사업자 계정 연동
- 전국 단위 서비스
- 실시간 주차 데이터가 확보되지 않은 주차장의 실제 혼잡도 보장

        ↓

        ↓
사용 가능성 점수·실패 위험도 계산
        ↓
추천 순위와 추천 이유 생성
        ↓
지도·목록·상세·비교 화면 제공
        ↓

# 9. AI·추천 요구사항

## 9.1 MVP 점수 산출

초기에는 과거 이력 부족으로 인해 머신러닝 확률이 아닌 규칙 기반 사용 가능성 점수를 제공한다.

| 평가 항목 | 초기 가중치 예시 |
|---|---:|
| 현재 사용 가능 충전기 비율 | 30% |
| 충전기 수 안정성 | 15% |
| 상태정보 최신성 | 15% |
| 예상 도착시간 | 15% |
| 과거 동일 시간대 가용률 | 10% |
| 주차 혼잡도 | 5% |
| 운영시간·이용 제한 | 5% |
| 교통·날씨 위험 | 5% |

가중치는 EDA와 사용자 테스트 결과에 따라 수정하며 설정 파일 또는 DB에서 관리한다.

## 9.2 머신러닝 확장

목표변수:

> 예상 도착시각에 해당 충전소에서 사용 가능한 충전기가 한 대 이상 존재하는가

- 1: 사용 가능
- 0: 사용 불가능

후보 모델:

- Logistic Regression
- Random Forest
- XGBoost 또는 LightGBM
- 시계열 기반 모델

평가 지표:

- Precision
- Recall
- F1-score
- ROC-AUC
- Brier Score
- Calibration
- Top-K Success Rate

모델 데이터는 시간 순서를 유지하여 학습·검증·테스트로 분리한다.

# 16. 완료 및 인수 기준

다음 조건을 모두 충족하면 MVP 요구사항이 완료된 것으로 판단한다.

1. 사용자가 GPS 또는 주소로 출발 위치를 입력할 수 있다.
2. 대구 지역 후보 충전소가 지도와 목록에 표시된다.
3. 충전기별 상태와 갱신 경과시간을 확인할 수 있다.
4. 후보 충전소별 ETA와 예상 도착시각이 제공된다.
5. 충전소별 사용 가능성 점수와 실패 위험도가 표시된다.
6. 각 추천 결과에 최소 2개 이상의 추천 또는 주의 이유가 제공된다.
7. 가까운 충전소라도 데이터가 오래되거나 충전기 수가 적으면 후순위가 될 수 있다.
8. 실데이터와 목데이터가 명확히 구분된다.
9. 단일 외부 API 장애가 발생해도 기본 추천 결과가 제공된다.
10. 충전기 상태 이력이 지정 주기에 따라 저장된다.
11. 모바일 환경에서 검색, 추천 목록, 상세 화면을 이용할 수 있다.
12. API 키가 프론트엔드와 공개 저장소에 노출되지 않는다.
13. 점수는 실제 충전 가능성을 보장하지 않는 예상 결과임이 안내된다.

# 17. 서비스 안내 문구

본 서비스가 제공하는 사용 가능성 점수와 충전 실패 위험도는 실시간 충전기 상태, 예상 이동시간, 상태 갱신시각, 충전기 수, 교통, 주차 및 날씨정보를 기반으로 계산한 예상 결과입니다. 실제 충전기 상태는 이동 중 변경될 수 있으며 충전 가능성을 보장하지 않습니다.
