# 2026-07-15 외부 공공 API 이슈 기록

전체 검증 스크립트: `scripts/api-tests/test-all-apis.ps1`

## 1. 한국환경공단 충전소 API — 발급 직후 403 (해결됨)

- 증상: 활용신청 승인 직후 호출 시 `403 Forbidden` (틀린 키는 401이므로 키 문제 아님)
- 원인: 공공데이터포털 인증키가 제공기관 서버로 동기화되기까지 약 1시간 소요
- 해결: 약 4시간 후 정상 (`resultCode: 00`)
- 교훈: 신규 발급 키의 403은 우선 동기화 대기

## 2. 공공데이터포털 API 간헐적 502/504 (상시 주의)

- 증상: 충전소 API가 첫 호출에서 502 또는 504를 반환하고 재시도하면 성공
- 대응: 모든 수집기·백엔드 호출에 재시도(백오프) 필수. 검증 스크립트에도 1회 재시도 내장

## 3. 대구 교통소통정보(신)·돌발 교통정보(신) — 원본 서버 404 → **2026-07-22 복구**

## 4. 대구 주차장 API — 로컬 401 (정상 동작)

- 증상: `pis.daegu.go.kr/api/serviceApply/prkInfo` 호출 시 401
- 원인: 신청 시 등록한 접속 IP(팀 AWS 서버 3.39.251.72)에서만 호출 허용. 로컬 PC IP는 차단됨
- 대응: 이 API 호출 코드는 AWS 서버에서만 실행. 로컬 개발은 목 데이터 사용

## 5. 대구 산책로 API — PARAMETER PARSING ERROR (해결됨)

- 증상: `returnReasonCode 100 (PARAMETER PARSING ERROR)`
- 원인: 좌표 파라미터명이 `x`/`y`가 아니라 `lat`/`lot`(경도가 lot), 반경은 km 단위, `type` 필수
- 해결: `?type=json&lat=35.8714&lot=128.6014&radius=5` 형식으로 호출

## 6. PowerShell 5.1 한글 스크립트/.env 인코딩 (해결됨)

- 증상: 한글 주석 포함 .ps1 실행 시 파싱 오류, .env 마지막 줄 파싱 실패
- 원인: PowerShell 5.1은 BOM 없는 UTF-8을 ANSI로 해석
- 해결: .ps1과 .env를 UTF-8(BOM) 으로 저장
