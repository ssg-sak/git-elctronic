## 2. 조치 유형별 사유

### 2.1 복원 (원본 의미 유지·보강)

| ID | 대상 | 전 | 후 | 사유 |
|---|---|---|---|---|
| R1 | status `statNm` | 거의 전부 결측 | info `statId+chgerId` 조인으로 복원 | 이름 분석·조인 가독성 |
| R2 | Tour 한글 | mojibake | latin1→utf-8 시도, 플래그 | 깨진 채 EDA 금지 |
| R3 | 주차 전일 운영시간 | 공백 | `0000`/`2400` **파생 컬럼** | 원본 결측은 보존 |

### 2.2 유지 (추정·대체 금지)

| ID | 대상 | 처리 | 사유 |
|---|---|---|---|
| K1 | status 미수집 (~97%) | `NO_STATUS_OBSERVED` | 미관측≠사용불가 |
| K2 | `output` 결측 | `output_missing` | 평균 대체 왜곡 |
| K3 | `useTime` 결측 | `operation_time_known=False` | 24시간 가정 금지 |
| K4 | `parkingFree` 결측 | `UNKNOWN` | 무료/유료 추정 금지 |
| K5 | 공원 roadNmAddr | 행 유지 | 지번·좌표로 충분 |
| K6 | city_tour email 등 | 원본 보존 | 피처 제외 가능 |

### 2.3 격리 (삭제 아님)

| ID | 대상 | 건수 | 파일 | 사유 |
|---|---|---:|---|---|
| Q1 | 충전기 좌표 이상 | 27 | `data/quarantine/charger_coordinate_suspects.csv` | `OUT_OF_BBOX` 26건(+ADDR 의심), `OUT_OF_BBOX`만 1건 |

공간·거리 조인 시 `coordinate_quality_flag==OK` 만 사용.

### 2.4 제외 (입력에서 안 씀)

## 3. 상태 코드 표준화 (후속 정합)

전처리 SANDBOX는 `stat_code_map.json` 중간 코드를 쓴다.  
서비스·가공 정본은 [`상태코드_매핑.md`](../data/스키마/상태코드_매핑.md) · `processing/cleansing.py` (2026-07-20 정합).

| 원천 | 표준 |
|---|---|
| 2 | 사용 가능 (`AVAILABLE`) |
| 3 | 사용 중 (`CHARGING`) |
| 4 | 고장 (`OUT_OF_ORDER`) |
| 5 | 점검 (`UNDER_INSPECTION`) |
| 1, 9, 결측·미관측 | 미확인 (`UNKNOWN`) |
