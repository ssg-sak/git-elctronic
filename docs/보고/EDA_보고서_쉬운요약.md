## 1. 우리가 하려는 일

> 그냥 가까운 곳이 아니라, **가서 충전기에 꽂을 가능성이 높은 곳**을 추천한다.

먼저 답해야 하는 것:

1. 상태를 **알기나** 하나? (관측)  
2. 알면 **지금 비었나?** (가용)  
3. 그 소식이 **얼마나 신선?**  
4. **몇 대**짜리인가?  
5. **급속/완속·플러그**가 맞나?  
6. **도착해도 문 열렸나?** (useTime + ETA)  
7. (참고) **몇 시·요일**에 더 비나? — 아직 잠정

①은 표로 정리하고, ②가 점수를 매긴다.

## 2. 어려운 말 → 쉬운 말

| 어려운 말 | 쉬운 말 |
|---|---|
| **관측** | CCTV가 그 칸을 **비춰서 상태를 안다** |
| **미관측** | **안 보여서 모름** (고장 아님) |
| **가용** | **비어 있어서** 쓸 수 있음 |
| **가용률** | 아는 칸 중 **빈 칸 비율** |
| **신뢰도 HIGH/NORMAL/CHECK** | 대략 5분 이내 / 15분 이내 / 그 이상·모름 |
| **충전소 / 충전기** | **한 장소** / 그 안 **콘센트 1대** |
| **chgerType** | 플러그·급완속 코드 (`02`=AC완속 …) |
| **잠정** | 며칠치라 **규칙으로 단정 금지** |

## 4. 충전기 유형 (급속/완속)

대구 충전기 대부분은 **`02` AC완속**. 급속만 고르면 후보가 확 줄어든다.

| 코드 | 이름 | 감각 |
|---|---|---|
| `02` | AC완속 | 완속 (제일 많음) |
| `04` | DC콤보 | 급속 |
| `06` | 멀티 | 급속 여러 규격 |
| `10`/`11` | 초급속 | 아주 빠름 |

유형(`chgerType`)과 상태(`stat`)는 **다른 축**이다.

## 6.5 진짜 문제 / 알고 쓸 것 (품질 게이트)

status **6/6 PASS · age ~4.5분**은 괜찮다. 그래도 아래는 **먼저 막아야** 추천·지도가 안 깨진다.

### 진짜 문제 (우선)

1. **좌표 오염** — `35,128` 허값, 대구 주소인데 평택/대전/강원 좌표 → 거리·지도 망가짐 → **후보 제외**

## 7. 한 장 정리

```text
[모름]  ──미관측──▶  빈자리로 세지 말 것
[앎] ──비어 있음──▶  가용 / 차 있음──▶ 사용 중

+ 신선하냐?     → age ~4.5분대면 비교적 믿기 (effective 등급)
+ 몇 대냐?      → 1대 위험 · 여러 대 여유
+ 급완속이냐?   → chgerType 필터
+ 문 열렸냐?    → useTime + (now+ETA)
+ 얼마나 걸리냐? → TMAP (직선 금지 · BE)
+ 몇 시냐?      → 저녁 더 붐빔 경향 (잠정)
```

**몇 점 줄지 / 어디로 보낼지 = ②**
