# EV SafeCharge — 과거 충전 이력 기반 혼잡도(Busy Risk) 심층 분석 보고서

**작성일**: 2026-07-28  
**작성자**: AI·데이터 ① (데이터·파이프라인)  
**분석 대상**: 대구 환경부(ME) 공용 충전소 과거 이력 데이터 (약 13만 건, 2026-07-24 추출본)

## 1. 개요 및 목적

현재 EV SafeCharge가 수집하는 **실시간 상태(Status) 데이터**는 지금 당장 빈자리가 있는지(가용성)를 알려주지만, "사용자가 도착했을 때 금방 차버릴 위험(Busy Risk)"을 예측하기에는 누적 기간이 짧습니다. 
이를 보완하기 위해 8개월간 누적된 **약 13만 건의 과거 충전 이력**을 심층 분석하여, 요일과 시간대별로 특정 충전소가 얼마나 붐비는지를 보여주는 **'혼잡도 프로파일(Lookup Table)'**을 구축했습니다.

이 프로파일을 통해 추천 모델은 실시간 가용성에 **"구조적 붐빔 위험(Busy Risk)"**이라는 사전 가중치를 반영하여 추천 점수를 정교하게 깎아낼 수 있습니다.

## 2. 파이프라인 구축 및 매핑 결과

- **데이터 정제 및 매핑**: 과거 데이터 상의 텍스트 노이즈(공백, 괄호 등)를 제거하여, 과거 이력의 128개 충전소를 현재 운영 중인 충전소 ID(`statId`)와 **100% 완벽하게 매핑**했습니다.
- **혼잡 점수(`demand_score`) 산출**: 
  - 각 `충전소(statId)` × `요일(0~6)` × `시간대(0~23)` 조합으로 총 14,931행의 룩업 테이블을 생성했습니다.
  - 해당 조합의 **총 점유 시간**(세션 수 × 평균 충전 시간)을 계산하고, 전체 데이터 기준 Min-Max Scaling을 적용해 **0~100점**의 `demand_score`를 부여했습니다.

## 4. DA② (AI/모델 파트) 활용 가이드

본 폴더에 동봉된 `station_hourly_profile.csv`를 추천 시스템 런타임 혹은 사전 배치 작업에 로드하여 다음과 같이 사용합니다:

1. 사용자의 요청 시간(또는 ETA 도달 시간)의 **요일**과 **시간** 추출
2. 추천 후보 충전소의 `statId`로 `station_hourly_profile.csv`를 룩업 (Lookup)
3. 해당 충전소의 현재 시간대 `demand_score` (0~100) 획득
4. `(100 - demand_score)`를 가용성 가중치로 곱하거나, 특정 임계점(예: 30점 이상) 초과 시 추천 순위에서 페널티 부여
