# EV SafeCharge — 차량 마스터(Vehicle Master) 구축 보고서

**작성일**: 2026-07-28  
**작성자**: AI·데이터 ① (데이터·파이프라인)  
**소스 데이터**: 한국전력공사 전기차량 모델별 정보 (20230718)

---

## 1. 개요 및 목적

앱 내 **'도착 예상 SOC 계산기'** 기능을 구현하기 위해서는 각 차종별 정확한 배터리 용량(kWh)과 공인 전비/주행거리가 필수적입니다.
한전 공공데이터를 통해 26개의 주요 전기차/PHEV 차종 목록(뼈대)을 확보하였으나, 원본 데이터에 스펙 꼬임(Jumbled) 현상과 배터리 용량 누락이 다수 발견되었습니다.

이를 해결하기 위해 파이프라인에서 각 차종별 **공식 제원을 하드코딩하여 100% 교정(보정)하는 로직**을 추가하였고, 추천 모델 및 프론트엔드에서 즉시 활용할 수 있는 정본 마스터 파일(`vehicle_master.csv`)을 생성했습니다.

## 2. 주요 교정 내역 (Corrections)

- **누락 데이터 복구**: 코나EV(64kWh), 볼트EV(66kWh), i3(37.9kWh), 레이(16.4kWh) 등 배터리 용량이 아예 없던(`NaN`) 차량의 제원을 공식 스펙으로 채워 넣었습니다.
- **꼬임 데이터 수정**:
  - `18년도 아이오닉 PHEV`에 잘못 들어간 코나EV 스펙(64kWh/406km)을 원래 스펙인 8.9kWh / 46km로 수정.
  - `SM3`에 잘못 들어간 니로EV 스펙(64kWh/385km)을 35.9kWh / 213km로 수정.
  - `테슬라 모델 S`의 비정상 배터리(24.4kWh)를 100kWh / 480km 급 스펙으로 수정.
- **충전 방식 정규화**: `fast_charge_type`(DC콤보, DC차데모, AC3상, 지원안함 등)과 `slow_charge_type`(AC완속)을 일관된 포맷으로 정리했습니다.

## 3. 파일 산출물

- **경로**: `docs/data/extracted/vehicle/vehicle_master.csv`
- **컬럼**: 
  - `manufacturer` (제조사)
  - `model_name` (모델명)
  - `battery_capacity_kwh` (배터리 용량)
  - `max_range_km` (최대 주행거리)
  - `fast_charge_type` (급속 충전 방식)
  - `slow_charge_type` (완속 충전 방식)

## 4. 활용 가이드 (프론트/백엔드/모델 팀)

- **프론트엔드**: 이 CSV 파일을 기반으로 앱 내 '내 차종 선택' 드롭다운 목록을 구성합니다.
- **프론트/백엔드**: 사용자가 차종과 현재 배터리 잔량(%)을 입력하면, 이 테이블의 `battery_capacity_kwh`를 조회하여 현재 남아있는 실제 에너지량(kWh)을 구하고, 길찾기 API의 이동 거리와 매칭해 도착 시 예상 SOC를 정밀하게 계산할 수 있습니다.
