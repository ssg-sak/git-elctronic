## 3. 평가 지표 정책

양성률이 높으므로 Accuracy는 주 지표로 사용하지 않는다. 모두 시간순 train/valid/test 분할에서 계산한다.

| 우선순위 | 지표 | 방향 | 용도 |
|---:|---|---|---|
| 1 | PR-AUC | 높을수록 좋음 | 희소한 실패·음성 탐지 성능 |
| 2 | 음성 Recall | 높을수록 좋음 | 충전 불가 후보를 놓치지 않는지 확인 |
| 3 | Brier Score | 낮을수록 좋음 | 확률 예측의 전반적 품질 |
| 4 | LogLoss | 낮을수록 좋음 | 과신한 확률에 대한 패널티 |
| 5 | Calibration | 오차가 작을수록 좋음 | 예측 확률을 실제 빈도처럼 해석할 수 있는지 확인 |
| 6 | ROC-AUC | 높을수록 좋음 | 보조적인 순위 분리 지표 |

Accuracy, 단일 랜덤 분할, 양성률만 높은 모델의 성능은 채택 근거로 사용하지 않는다. DA②는 class weighting 적용 여부와 persistence·규칙 기준선 대비 개선 여부를 함께 보고한다.

## 4. 피처 정책

### 기본 유지 후보

`available_count`, `usable_count`, `known_charger_count`, `total_chargers`, `observation_coverage`, `observation_age_minutes`, `horizon_minutes`는 도메인 필수 피처로 유지한다. 단, 최종 채택은 DA②의 시간 외 ablation 결과로 결정한다.

### 보류 피처

`sessions_per_charger`, `usage_daytype_avg`, `history_observed`는 이용이력 커버리지가 약 7.25%이고, 앞의 두 피처 결측률이 약 92.73%다. 현재 기본 모델에 넣지 않고 sparse-history ablation 전용으로 보류한다.

`direct_observation_coverage`, `available_count_delta_1tick`, 시간·요일 피처는 단변량 근거가 약하거나 horizon 방향성이 불안정하므로 HGB 상호작용 실험 전용으로 둔다.

`unobserved_rate`는 `observation_coverage`의 정확한 여집합이므로 중복 피처로 제외한다.

## 5. 결측값 정책

- 미관측 상태를 `0` 또는 사용 불가로 대체하지 않는다.
- 관측 커버리지와 `label_reason`을 별도 보존한다.
- 부분 관측 도착 시점은 학습 라벨에서 제외한다.
- 선택적 이용이력 결측은 기본값으로 임의 대체하지 않고, `history_observed`와 함께 별도 실험한다.
- 미래 시점 컬럼(`target_time`, `label_observed_at`, 도착 상태 집계)은 라벨 감사용으로만 보관하고 모델 입력에서 제외한다.
