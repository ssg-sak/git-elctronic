## 1. 결론

HistGradientBoosting 전용 수집기를 새로 만들지 않고 기존 AWS 상태 수집·중복 제거·25분 제한 상태 복원 패널을 재사용해 모델 공용 학습 마트를 생성했다.

DA① 품질 게이트는 PASS 18·WARN 4·FAIL 0이다. 기본키 중복과 미래 정보 누출은 0건이며, 보수적 음성 라벨과 시간 분할을 적용했다. 따라서 모델 실험용 데이터 전달은 가능하다.

다만 현재 데이터만으로 HGB를 최종 채택하면 안 된다. 수집 기간이 7일이고, 5분·10분 라벨이 거의 동일하며, 클래스 불균형이 존재한다. DA②는 최소 14일 이상 축적본으로 시간 외 평가·ablation·calibration을 수행해야 한다.

## 3. 라벨 정책

```text
양성 1:
도착틱에서 상태를 아는 충전기 중 가용 충전기가 1대 이상

음성 0:
도착틱에서 충전소 전체 충전기 상태가 확인됐고 가용 충전기가 0대

학습 제외:
일부 충전기만 확인됐고 확인된 범위에서 가용 충전기가 0대
```

부분 관측 0대를 음성으로 바꾸지 않는다. 음성 60,564행의 도착틱 상태 커버리지는 모두 100%다.

라벨은 25분 이내 마지막 상태를 유지하는 보수적 복원 패널을 사용한다. 수집 공백이 25분을 초과하면 상태를 이어 붙이지 않는다.

## 4. 시간 분할과 누출 방지

- 랜덤 행 분할을 사용하지 않았다.
- train·valid·test 날짜가 겹치지 않는다.
- 모든 피처는 `feature_as_of` 이하 정보만 사용한다.
- `target_time`, `label_observed_at`, 도착틱 충전기 수는 감사 컬럼이며 모델 입력에서 제외한다.
- 과거 이용 피처의 원천 기간은 2024-10-18~2026-03-31로 학습 패널보다 이전이다.
- 동일 충전소의 미래 행이 rolling·변화 피처에 들어가지 않는다.

## 5. 피처–타겟 관계

상관계수 0.5를 일괄 기준으로 사용하지 않았다. train 기간에서 point-biserial 상관, 보정 p-value, 단일 피처 AUC, 날짜 block-balanced AUC와 95% 신뢰구간, mutual information을 계산했다.

### DA① 피처 판단

| 판단 | 피처 |

이 판단은 DA① 단변량 게이트다. 최종 피처 채택은 DA②의 시간 외 HGB ablation 결과로 결정한다.

## 6. 품질 WARN

### 6.1 클래스 불균형

양성률이 92.41%다. Accuracy를 주 지표로 사용하면 안 된다. DA②는 Brier, LogLoss, PR-AUC, 음성 Recall과 class weighting 비교를 수행해야 한다.

### 6.2 5분·10분 horizon 중복

동일 `station_id × feature_as_of`에서 5분·10분 라벨이 모두 존재하는 210,084쌍 중 99.42%가 같은 타겟이다. 약 10분 수집 간격 때문에 두 horizon이 같은 미래틱에 매칭되는 경우가 많다.

DA② 권장안:

- MVP 비교에서는 10·15·30분을 우선 사용하거나
- 5분은 별도 모델로 주장하지 않고 10분 근사로 표시하거나
- 실제 5분 수집이 확보된 뒤 다시 학습한다.

### 6.3 기간 부족

현재 7일이다. 요일 반복과 운영 변화를 검증하려면 최소 14일, 가능하면 28일 축적 후 최종 모델을 승인한다.

### 6.4 과거 이용 피처 희소성

과거 이용 이력 조인율이 학습행 기준 7.27%다. 결측을 0으로 채우지 않으며 기본 HGB 피처에서 보류한다.
