# 도착 예정 시각 기반 전기차 충전소 추천 시스템 초안

팀 프로젝트 설계 초안 (Draft)  |  2026-07-23

## 1. 개요

본 문서는 지도에서 목적지를 설정하고 최적 경로·도착 예정 시각(ETA)을 산출한 뒤, 도착 시점 기준으로 목적지 근처 전기차 충전소의 사용 가능 확률(또는 평가 점수)이 높은 순으로 추천하는 서비스 초안이다.

프론트엔드 예시(TMAP ROUTE): 출발/도착 좌표, 예상 소요, 도착 예정, 총 거리 표시. 이 ETA를 예측 모델의 eta_minutes 입력으로 사용한다.

## 2. 사용자 시나리오

- 사용자가 지도에서 출발지·목적지를 지정한다.

- 경로 API(예: TMAP)가 최적 경로와 도착 예정 시각·소요 시간(ETA)을 반환한다.

- 시스템은 도착 좌표 주변 충전소를 거리 기준으로 조회한다.

- 각 충전소에 대해 지금으로부터 ETA분 뒤 사용 가능 확률을 예측한다.

- 점수(확률·예상 잔여 대수 등)가 높은 순으로 추천 리스트를 보여준다.

## 3. 시스템 구성

### 3.1 데이터 수집

- ev_charger_status: 충전기 실시간 상태 로그 (약 5분 간격, getChargerStatus)

- ev_charger_info: 충전소/충전기 마스터 (이름, 주소, lat/lng, 타입, 출력 등, getChargerInfo, 일 1회)

- ev_charger_features: 파생 피처 (시간대, 가용 비율, 충전 경과 시간 등)

### 3.2 예측 모델

- 목표: H분 뒤(도착 시점) 충전기가 사용 가능(stat=2)할 확률

- 핵심 입력: eta_minutes(H), 현재 상태, features, 충전기 정보(타입·출력 등)

- 주력 모델: HistGradientBoosting Classifier

- 학습 horizon 예: 5, 10, 15, 20, 30, 45, 60분

- 충전소 점수: 충전기별 확률 평균 또는 확률 임계값 이상 대수 / 전체 대수

### 3.3 경로·지도

- 경로·ETA: TMAP(또는 동등 Directions API)

- 충전소 위치: ev_charger_info.lat / lng

- 근처 검색: 도착 좌표 기준 반경(예: 1~3km) 또는 상위 K개

## 4. 추천 파이프라인 (초안)

- 1) 클라이언트: 출발·도착 좌표 전달

- 2) 경로 API: duration_sec, arrival_datetime, distance 반환

- 3) eta_minutes = ceil(duration_sec / 60) (필요 시 가장 가까운 horizon으로 매핑)

- 4) DB: 도착점 근처 충전소 조회 (Haversine 거리)

- 5) 각 충전소의 최신 충전기 상태 + features + eta_minutes 로 모델 추론

- 6) 충전소 단위 집계 점수 산출 후 내림차순 정렬

- 7) 추천 리스트 응답 (이름, 거리, 주소, 확률/점수, 예상 잔여 대수)

## 5. 추천 점수 정의 (초안)

점수 후보는 아래 중 하나 또는 가중합을 사용한다.

- available_prob_avg: 충전기 사용가능 확률 평균

- expected_available_count: 확률 합 또는 (확률>=0.5) 대수

- availability_rate: 예상 사용가능 대수 / 전체 충전기 수

- distance_penalty: 거리가 멀수록 감점 (선택)

- 최종 score 예: 0.7 * availability_rate + 0.3 * (1 - normalize(distance))

## 6. API 응답 예시 (초안)

## 7. UI 표시 항목 (초안)

- 충전소명, 거리, 주소

- 도착 시점 기준 사용 가능 확률(또는 종합 점수)

- 예상 잔여 대수 (예: 6대 중 약 5대)

- 안내 문구: "약 N분 뒤 도착 기준 예상"

- 선택: 급속/완속, 주차 무료 여부 뱃지

## 9. 현재 구현 현황

- 수집: run.py(상태), run_info.py(정보)

- 피처: build_features.py → ev_charger_features

- 모델 평가: analyze_three_tables.py, analyze_horizon.py

- horizon 평가 요약(예시): HGB 전체 ROC-AUC 약 0.91, 5분대 높고 60분대로 갈수록 하락

## 10. 향후 과제

- TMAP ETA와 추천 API 연동

- 근처 충전소 검색 + 랭킹 API 구현

- 프론트 추천 리스트 UI

- 데이터 축적(수일~2주) 후 30~60분 horizon 재학습

- period=5 수집 한계 보완(전체 스냅샷 주기 수집 검토)
