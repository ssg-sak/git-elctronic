# 대구 EV 세이프차지 EDA 계획서

| 항목 | 내용 |
|---|---|
| 프로젝트 | EV SafeCharge |
| 목적 | 가까운 충전소가 아니라 **도착 시 실제로 사용할 가능성이 높은 충전소** 추천 |
| 기준 데이터 | `SANDBOX_20260716_preprocess_pipeline/data/processed/` |
| 작성일 | 2026-07-16 |
| 전제 | 현재 데이터는 단일 시점 스냅샷 중심이며, 예측 성능 검증용 데이터가 아니다 |

## 1. 핵심 질문

> “현재 가장 가까운 충전소는 어디인가?”가 아니라  
> “사용자가 실제로 도착했을 때 가장 높은 확률로 사용할 수 있는 충전소는 어디인가?”

EDA는 다음 의사결정을 지원한다.

| 의사결정 | EDA에서 확인할 것 |
|---|---|
| 상태정보가 충분히 수집되는 충전소는 어디인가 | `status_coverage_rate`, 운영기관·충전기 유형별 수집률 |
| 현재 사용 가능한 충전기가 많은 지역은 어디인가 | 관측 상태 기준 `available_count`, 구·군·공간 분포 |
| 충전기 수는 많지만 상태 신뢰도가 낮은 곳은 어디인가 | `charger_count` vs `unknown_status_rate` |
| 충전기 수가 적어 실패 위험이 높은 곳은 어디인가 | 충전소당 충전기 수, 단일 충전기 충전소 |
| 운영조건이 실제 이용 가능성을 낮추는가 | `limitYn`, `is_24h`, `parkingFree`, `is_service_target` |
| 교통·돌발이 도착시간에 어떤 영향을 주는가 | mock 기반 구조 검증, 실데이터 확보 후 재검증 |
| 도착시간 증가가 상태 신뢰도를 낮추는가 | `status_age_seconds + estimated_travel_time` |
| 충전 중 이용 가능한 관광지·공원은 있는가 | 반경별 POI·공원 수, 최근접 거리 |
| 예측모델 전 추가 수집은 무엇인가 | status 시계열, 요청/도착/선택 로그, TMAP, 교통 실데이터 |

## 2. 반드시 반영할 데이터 한계

| 한계 | EDA 표현 원칙 |
|---|---|
| 충전기 기본정보 25,335건 / 상태정보 593건 | 상태 커버리지 **2.3406%** 를 모든 상태 분석 앞에 명시 |
| 상태정보 없음 | **사용 불가가 아니라 미관측** (`status_missing=True`) |
| 대부분 단일 시점 스냅샷 | 시간대 패턴·예측 성능처럼 표현 금지 |
| 주차·교통 데이터는 mock | 구조 검증·규칙 실험용으로만 해석 |
| 날씨는 `nx=89, ny=90` 단일 격자 | 대구 전역 공간 차이 분석 금지 |
| 일부 관광지(city_tour)는 좌표 없음 | 공간 분석 제외, 지오코딩 대기 테이블로 분리 |
| 도착 시 사용 가능 여부 라벨 없음 | 완전한 `available_at_arrival` 모델 학습 불가 |
| 현재 데이터로 가능한 모델 | 예측모델이 아니라 **규칙 기반 위험점수 프로토타입** |

## 3. 분석 단위 정의

| 단위 | 기본키 | 대표 테이블 | 주요 분석 |
|---|---|---|---|
| 충전기 | `statId + chgerId` | `charger_master`, `charger_current_view` | 상태, 유형, 출력, 미관측 여부 |
| 충전소 | `statId` | `charger_current_view` 집계 | 충전기 수, 관측 가용 수, 운영조건 |
| 주차장 | `pkltId` | `parking_current` | 잔여면, 점유율, 실시간 미수집 |
| 교통 링크 | `linkId` | `traffic_link_current` | 속도, 혼잡, 통행시간 |
| 돌발상황 | `incidentId` | `traffic_incident_current` | 유형, 심각도, 활성 여부 |
| 시간 | 상태갱신·예보·도착예정시각 | status/weather/traffic | 신뢰도·예보 리드타임 |
| 공간 | lat/lng, 구·군, 반경 | charger/parking/poi/traffic | 접근성, 밀집, 좌표 오류 |

**주의**: 충전기 row와 충전소 row를 혼용하지 않는다. 충전소 분석은 반드시 `statId` 집계 후 수행한다.

## 4. 현재 스냅샷 EDA vs 향후 예측모델 EDA

| 구분 | 현재 단일 스냅샷 EDA | 반복 수집 후 예측모델 EDA |
|---|---|---|
| 목적 | 데이터 품질·구조·규칙 피처 검증 | `available_at_arrival` 예측 타깃 검증 |
| 가능 분석 | 빈도, 분포, 교차표, 커버리지, 공간 분포 | 시간대 패턴, 점유 지속시간, 리드타임 효과 |
| 불가능/보류 | 미래 사용 가능성 성능 주장 | 모델 학습·검증 가능 |
| 교통/주차 | mock 구조 검증 | 실시간 데이터 기반 지연·혼잡 효과 |
| 날씨 | 단일 격자 보조 변수 | 다중 격자·시간 누적 효과 |
| 산출 | 규칙 기반 점수 후보 | supervised model feature/target |

## 6. 통계적 검토 계획

### 현재 가능한 분석

- 빈도분석, 분포분석, 교차표
- 상태 수집 커버리지
- 데이터 품질 분석
- 공간 분포
- 규칙 기반 위험점수 실험
- 효과크기 중심의 탐색적 관계 분석

### 현재 신뢰성 있게 어려운 분석

- 시간대별 사용 패턴
- 충전 점유 지속시간
- 미래 사용 가능 여부 예측
- 날씨와 충전 가능성 변화
- 교통 혼잡과 충전 가능성 인과관계
- 주차 혼잡과 충전 성공 여부

### 검정 후보

| 관계 | 방법 | 조건 |
|---|---|---|
| 범주형↔범주형 | 카이제곱, Cramér’s V | 기대빈도 확인 |
| 연속형↔이진 | Mann–Whitney U, 효과크기 | 정규성 불필요 |
| 연속형↔연속형 | Pearson/Spearman | 선형성·순위관계 구분 |
| 평균 비교 | t-test | 정규성·등분산성 확인 후 |

p-value 단독 제시 금지. 표본수, 효과크기, 신뢰구간을 함께 제시한다. 25,335 row라도 시간 독립 관측치가 25,335개라는 뜻은 아니다.
