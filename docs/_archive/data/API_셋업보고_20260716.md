## 1. 작업 개요

당일 공공데이터포털(data.go.kr) 인증키 발급·연동 검증 후, 대구 MVP용 CSV 추출까지 진행했다.  
오전 전수 검증 → 오후·저녁 재추출 → 중복 CSV 정리 → 포털 승인 항목과 실제 HTTP 결과 대조까지 반영한다.

**한 줄 요약**: 충전·기상(초단기·단기)·TourAPI·산책로는 CSV 확보. 교통(승인·404)·대구시 관광지(403)·카카오/TMAP(mock)·주차(AWS 전용)는 미확보.

## 4. 트러블슈팅 이력

### 이슈 1: 키 발급 직후 401 Unauthorized
- **원인**: 신규 키 서버 동기화 최대 ~1시간
- **해결**: 대기 후 정상 인증 확인

### 이슈 2: PowerShell `-Command`에서 `&` 파싱 오류
- **원인**: 인라인 `-Command`에서 `&`가 예약 연산자
- **해결**: `.ps1` 파일 + `-Body` 해시테이블

```powershell
# ✅
$params = @{ serviceKey = $key; pageNo = "1" }
Invoke-RestMethod -Uri "https://..." -Body $params
```

### 이슈 3: .env UTF-8 / PowerShell 인코딩
- **원인**: BOM 없는 UTF-8을 ANSI로 읽어 키 파싱 실패
- **해결**: `ForEach-Object` 패턴 + UTF-8(BOM) 권장

### 이슈 4: 기상 `getVilageFcst` APPLICATION_ERROR
- **원인**: `base_time`이 발표 시각(02/05/08/11/14/17/20/23)과 불일치
- **해결**: 직전 발표시각으로 맞춤 → 저녁 추출 성공 (1,000건)

### 이슈 5: 산책로 CSV가 `System.Object[]`로 깨짐
- **원인**: 응답이 `body.items.item[]`인데 상위 `items`만 flatten
- **해결**: `items.item` 명시 파싱 → 107건 정상 CSV

### 이슈 6: 교통 API 404 (승인 후에도 동일)
- **원인**: 자격 문제면 401/403. 404는 대구시 원본(ATMS) 경로 장애로 판단 (7/15부터 동일)
- **대응**: 포털 오류신고 또는 교통정보운영과 **053-803-6715**. 복구 후 `extract-new-only.ps1` 재실행

### 이슈 7: 대구시 관광지 403 (Tour와 혼동 주의)
- **원인**: 한국관광공사 TourAPI(이미 OK)와 **다른 API**. 동일 키·동일 기관 대역(`6270000`)이라도 관광지만 403
- **대응**: 마이페이지에서 `대구 관광지`/`getTourKorAttract` 승인·동기화 재확인. 승인 직후 ~1시간 대기 후 `extract-city-tour.ps1` 재시도
