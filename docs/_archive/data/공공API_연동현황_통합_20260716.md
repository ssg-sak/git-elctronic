## 2. 인증키 기준 (확정)

### 2.1 핵심 규칙

> **data.go.kr 인증키는 계정당 1개.**  
> API마다 **활용신청**은 따로 하지만, 키 문자열은 동일하다.

| 구분 | 변수 | 현재 (로컬 `.env`) | 비고 |
|---|---|---|---|
| 공공데이터포털 공통 | `DATA_GO_KR_KEY` | Decoding 키 설정됨 | 충전·기상·Tour·교통·산책 등 **전부 이 키** |
| TMAP | `TMAP_APP_KEY` | `MOCK_KEY_FOR_LOCAL_TESTING` | 실키 미반영 → 403 |
| 카카오 | `KAKAO_REST_KEY` | `MOCK_KEY_FOR_LOCAL_TESTING` | 실키 미반영 → 401 |
| 대구 주차 기본 | `DAEGU_PARKING_KEY` | mock | AWS IP(`3.39.251.72`)만 허용 |
| 대구 주차 실시간 | `DAEGU_PARKING_RT_KEY` | mock | 위와 동일 |

> `.env`는 커밋 금지. 키 값은 문서에 적지 않는다. 확인은 로컬 `git-elctronic/.env`만.

### 2.2 Encoding vs Decoding

| 종류 | 사용 |
|---|---|
| Encoding (`%2B` 등) | URL에 직접 붙일 때 |
| **Decoding (원본)** | `requests` / `Invoke-RestMethod -Body` — **우리가 쓰는 방식** |

### 2.3 동기화

- 신규·재발급 직후 **최대 ~1시간** `401`/`403` 가능 → 활용신청 승인 + 동기화 대기
- 1시간 후에도 403이면: 해당 API **활용신청 승인** 재확인
- **주의**: 승인 지연은 보통 401/403. **404는 승인 문제가 아님** (경로/원본 서버)

## 3. 연동 검증·추출 현황 (2026-07-16)

### 3.1 포털 활용신청 vs 실제 호출 (중요)

오늘 마이페이지에 **[승인]** 으로 보이는 것과, 스크립트가 받는 HTTP는 아래처럼 갈린다.

| 포털 승인 항목 (신청일 2026-07-16) | 실제 호출 | 비고 |
|---|---|---|
| **한국관광공사_국문 관광정보 서비스_GW** | ✅ **200** / CSV **57건** | 이미 추출됨. 키·승인 정상 |
| **대구광역시_교통소통정보(신)** | ❌ **404** | 승인됐는데도 Not Found → **원본 서버 장애** |
| **대구광역시_돌발 교통정보(신)** | ❌ **404** | 위와 동일 |
| (별개) 대구시 관광지 `getTourKorAttractList` | ❌ **403** | TourAPI와 **다른 상품**. Tour 승인과 무관 |

> **활용신청 [승인] ≠ 지금 당장 데이터가 온다**  
> 승인은 “이 키로 호출할 자격”. 제공기관 서버가 살아 있어야 JSON/XML이 내려온다.

### 3.3 왜 “승인했는데” 에러인가

**1) 한국관광공사 TourAPI**  
- 승인 맞음 → **이미 정상 동작**.  
- 헷갈리기 쉬운 점: 예전에 실패로 적힌 **대구시 관광지(403)** 는 이름이 비슷하지만 **다른 API**다.

**2) 대구 교통 2종 (소통·돌발)**  
- 포털 승인 OK.  
- 그런데 공식 URL 호출 시 **HTTP 404 Not Found** (본문 거의 없음).  
- 자격 없으면 보통 **401/403**이 난다. **404 = 경로가 없거나 대구시 ATMS 원본이 죽은 상태**.  
- 팀 기록상 7/15부터 동일. 문의: 포털 오류신고 또는 교통정보운영과 **053-803-6715**.

**3) 대구시 관광지 403**  
- Tour(한국관광공사) 승인 목록에 있는 항목과 **다름**.  
- 마이페이지에 `대구 관광지` / `getTourKorAttract` 가 **별도 [승인]** 인지 확인해 보면 됨.

## 4. 호출·추출 방법 (가이드 요약)

### 4.1 PowerShell (권장)

```powershell
# -Body 해시테이블 — URL에 & 직접 붙이지 말 것
$params = @{
    serviceKey = $env:DATA_GO_KR_KEY   # 또는 .env에서 읽은 Decoding 키
    pageNo     = "1"
    numOfRows  = "10"
    zcode      = "27"   # 대구
}
$r = [xml](Invoke-RestMethod -Uri "https://apis.data.go.kr/B552584/EvCharger/getChargerInfo" -Body $params -TimeoutSec 90)
# resultCode 00 = 정상
```

### 4.3 EvCharger 주요 파라미터·코드

| 파라미터 | 설명 |
|---|---|
| `zcode=27` | 대구 |
| `period` | status 최근 N분 변경분 (예: 10) |
| `numOfRows` / `pageNo` | 페이징 |

| `stat` | 의미 |
|---|---|
| 2 | 충전 대기(사용 가능) |
| 3 | 충전 중 |
| 4 | 운영 중단 |
| 5 | 점검 중 |
| 9 | 통신 이상 |

### 4.4 기상청

- 대구 격자: **nx=89, ny=90**
- 초단기: `base_time`을 발표 시각에 맞게
- 단기예보(vilage): 발표 시각(02/05/08/11/14/17/20/23시) — **오늘 추출 성공(1000건)**

### 4.5 산책로

- 파라미터: `type=json`, `lat`, `lot`(경도), `radius`(km)
- 응답: `body.items.item[]` — **오늘 107건 추출 성공**

## 5. 오류·대응 (통합)

| 증상 | 원인 | 대응 |
|---|---|---|
| 401 / 403 (data.go.kr) | 키 동기화 / 해당 API 활용신청 | 1시간 대기 → 마이페이지 **그 API** 승인 확인 |
| **404 (교통)** | 대구시 ATMS 원본 장애 (승인 무관) | 오류신고 / 053-803-6715 |
| 카카오 401 / TMAP 403 | 로컬 mock 키 | `.env`에 실키 반영 후 재추출 |
| 주차 로컬 401 | IP 화이트리스트 | AWS에서만 실호출, 로컬은 mock |
| PowerShell `&` 파싱 | 인라인 `-Command` | `.ps1` + `-Body` |
| EvCharger 502/504 | 게이트웨이 간헐 장애 | 재시도(백오프) |

상세 이력: `docs/troubleshooting/2026-07-15_공공API_이슈.md`
