# EV SafeCharge 데이터 파트 작업 가이드

| 항목 | 내용 |
|---|---|
| **대상** | AI·데이터 담당 2명 |
| **구분** | **DA➀** 데이터·파이프라인 · **DA➁** 모델·평가·서빙 |
| **현재 단계** | 충전기 상태 **실수집(2주)** + **목데이터**로 전처리·특성·추천·평가 **구조 선개발** |
| **정본** | 본 문서. 세부 스키마·매핑·완료 체크는 하위 문서와 **1:1 연결** |

```
목 상태 이력 → 품질 점검 → 패널 재구성 → 특성 생성 → (규칙 점수·추천=DA➁) → 실수집 JSON/CSV로 입력 교체
```

## 1. 데이터 파트 공동 목표

실제 상태 이력을 **2주간** 모으는 동안 기다리지 않는다.

1. **목데이터**(`json/` · `*_mock*`)로 전체 파이프라인 코드를 먼저 만든다.
2. 실수집이 준비되면 **입력 파일만 교체**한다 (함수·행 단위·컬럼 의미 유지).
3. **실진행 본데이터**와 **실험 목데이터**는 트랙을 분리한다 → [`data/실데이터_목데이터_트랙.md`](./data/운영/실데이터_목데이터_트랙.md)

| 단계 | 담당 | 저장소 위치 |
|---|---|---|
| 목·실 이력 입력 | DA➀ | `json/charger-status-history.json` · 실수집→동일 스키마 export |
| 품질·패널·특성 | DA➀ | `apps/data-pipeline/processing/` |
| 규칙 점수·추천·평가 | DA➁ | `packages/recommendation-core/` |
| 타입·API 규격 | DA➁·백엔드 | `packages/shared-types/` · `docs/API_계약.md` |

## 3. 역할 구분

### DA➀ 데이터·파이프라인

- 원천 구조·데이터 사전 · 상태코드 표준화 · 품질 점검
- **공백 안전 패널** 재구성 · EDA · 특성·데이터셋(D1/D2)
- **하지 않음:** 점수·위험도·추천 이유·모델 실험·서빙

### DA➁ 모델·평가·서빙

- 문제 정의 · 거리순 baseline · 규칙 점수 · 위험도·추천 이유
- 모델·평가 · 백엔드 추론 함수

### 행 단위 (필수 합의)

> **기준시각 T × 충전소 S** 의 상태·주변 조건

예: `2026-07-20 10:30 / MOCK-ST001 / (도착 15분 후 사용 가능 여부)`

저장소 정본: [`docs/data/스키마/데이터셋_명세.md`](./data/스키마/데이터셋_명세.md) — D1=스냅샷 1행/소, D2=소×시각 패널.

## 4. DA➀ 작업

### 4.1 원천 데이터 사전

| 공식 컬럼 | 의미 | 내부(EvCharger) 대응 |
|---|---|---|
| `stationId` | 충전소 ID | `statId` |
| `chargerId` | 충전기 ID | `chgerId` |
| `status` | 표준 상태 | `stat` → 매핑 |
| `statusUpdatedAt` | 원천 갱신 시각 | `statUpdDt` |
| `observedAt` | 우리 수집 시각 | `fetchedAt` / `snapshotId` |
| `latitude` / `longitude` | 좌표 | `lat` / `lng` |

정본: [`docs/data/스키마/데이터_사전.md`](./data/스키마/데이터_사전.md)

### 4.2 상태코드 표준화

**API·목데이터 4값** (본 가이드):

| 표준값 | 의미 |
|---|---|
| `AVAILABLE` | 충전 가능·대기 |
| `CHARGING` | 충전 중 |
| `OUT_OF_SERVICE` | 고장·점검·통신오류 등 사용 불가 |
| `UNKNOWN` | 미확인·해석 불가 |

**내부 5값** (세분화·EDA): `OUT_OF_ORDER` · `UNDER_INSPECTION` — [`상태코드_매핑.md`](./data/스키마/상태코드_매핑.md)

코드: `processing/status_standard.py` · `processing/cleansing.py`

### 4.3 목 상태 이력 불러오기

```python
import pandas as pd
from mock_loader import load_charger_history

history = load_charger_history()  # json/charger-status-history.json
print(history.head())
```

첫 점검: 행 수 · 충전소/충전기 수 · observedAt 범위 · 중복 · 상태 목록 · 결측

### 4.4 품질 점검

```python
from history_validate import validate_history, save_quality_report

report = validate_history(history)
save_quality_report(report, path="docs/data/quality/mock_history_report.json")
```

### 4.5 공백 안전 패널

원칙: 시간순 정렬 → 충전기별 마지막 상태 유지 → **시점당 충전기 1표** → **25분 초과 공백** 시 구간 분리

```python
from gap_safe_panel import build_gap_safe_panel

panel = build_gap_safe_panel(history, max_gap_minutes=25)
```

코드·테스트: `processing/gap_safe_panel.py` · `evaluation/tests/test_gap_safe_panel.py`
