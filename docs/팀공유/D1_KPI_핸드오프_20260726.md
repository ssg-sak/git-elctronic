## ②·백엔드가 바로 사용할 계약

후보 생성 순서:

```text
recommend_public_default=true
→ coord_ok=true
→ is_operating_now != "N"
→ 상태 신선도와 미관측은 경고로 표시
→ has_confirmed_available=true는 “즉시 충전 가능” 탭의 강한 조건
→ ETA는 요청 시점 TMAP 경로 결과를 결합
```

### null 해석

- `observed_count=0` 또는 `unobserved_rate`가 높음: **사용 불가가 아니라 미관측**
- `nearest_parking_m` null: 1km 이내 Team5 주차장 미조인
- `parking_remaining_spaces` null: 최신 주차 잔여면 정보 없음
- `nearest_incident_m` null: 반경 내 UTIC 돌발 미조인
- `eta_minutes` null: 백엔드 런타임 ETA 미결합
