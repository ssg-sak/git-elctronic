# 이름 쉬운말 안내 (조장·본인용)

코드/폴더에 예전 약어가 남아 있어도, **말할 때는 아래만** 쓰면 된다.

| 예전에 부르던 말 | 이제 이렇게 | 뜻 |
|---|---|---|
| D1 | **현재표** | 지금 시각 기준, 충전소마다 한 줄 요약 |
| D2 | **시간표** | 충전소를 시간 따라 쌓은 상태 이력 |
| snapshot | 현재표 파일 | `station_feature_snapshot_latest.*` |
| panel | 시간표 파일 | `station_feature_panel_latest.parquet` |
| tick 패널 | 틱 복원표 | 수집 시각마다 상태 복원한 표 (과거 재생용) |
| as_of | 기준시각 | 현재표를 찍은 “지금” |

점수·추천 순위는 이 표들에 **없음**. 표 → ②/조장이 모델·점수.

```
DA① | plain names | 20260808
```
