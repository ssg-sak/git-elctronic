회의 **B구간(약 12분)** 용. 읽듯이 말해도 되게 짧게.

---

## 1. 한 줄 결론 (30초)

> 데이터 층은 끝났습니다.  
> 상태: **`DA1_READY_FOR_DA2_MODEL_EVALUATION`**.  
> 지금부터 점수·추천·API·화면은 **②·BE·FE**가 이어가면 됩니다.

---

## 2. 왜 데이터가 필요한지 (1분)

서비스 목표: 가까운 곳이 아니라 **도착했을 때 충전 가능할 가능성이 높은 곳**.  
그러려면 실시간 상태 + **언제 갱신됐는지** + 시간 패턴이 표로 있어야 한다.  
①이 그 표를 만들었다.

---

## 3. 만든 것 (3분)

| 산출 | 쉬운 말 | 규모 |
|---|---|---|
| **현재표** | 충전소마다 “지금” 한 줄 | **4,210**행 · as_of `2026-08-09T07:23:21+09:00` |
| **시간표** | 충전소×시각 | snaps **~2960** · 행 **~9.12M** |

| **스키마·KPI·EDA** | 계약·품질·패턴 | validate **FAIL 0** |

경로 (같이 볼 때 말함):

- 시간표: `.../station_feature_panel_latest.parquet`
- 스키마: `docs/data/스키마/`

---

## 4. 전처리에서 팀이 같이 기억할 것 (2분)

1. **중복** → `(statId, chgerId)` 최신 `statUpdDt`만  
2. **stat 매핑** → 2=가능, 3=사용중, 4=고장, 5=점검, 1·9=미확인 (**미확인≠고장**)  
3. **gap-safe** → 스냅 간격 25분 넘으면 채우지 않고 끊음  
4. **가용률** → 가능/(가능+사용중) · 미관측·고장·점검 분모 제외  
5. **신선도** → 5분/15분 기준 · CHECK 많아도 기준 완화 안 함

EDA 한 줄: **낮(11시 전후)에 더 비고, 밤(22시 전후)에 더 찬다.**

---

## 5. 일부러 안 넣은 것 — HOLD (2분)

오늘 합의 안건으로 넘김. 보고만:

| HOLD | 이유 |
|---|---|
| 주차 realtime | 커버 얇음 → **점수 금지** |
| usage 이력 | 희소 → 과적합 위험 |
| UTIC 주력 | 수집 제약 · KPI K3 FAIL |
| 학습 ETA | **동대구역 고정** · 서빙은 사용자 위치 TMAP |

---

## 6. 안 한 것 (명확히) (1분)

- 추천 **점수** · Top-N · 추천 이유  
- REST API · 프론트 화면  
- “이 모델로 서비스한다”는 **운영 확정**

HGB 숫자는 **피처 세트 점검**용이다. 운영 모델은 **②**.
