## 무엇을 모았는가

주력은 **공공데이터포털(data.go.kr) EvCharger** — 충전소 정보·실시간 충전기 상태다.  
보조로 교통·ETA·주차·관광 등을 붙였고, MVP 점수에 넣을지 여부는 품질에 따라 **HOLD**했다.

| 구분 | 출처 | 역할 |
|---|---|---|
| 충전기 상태·정보 | EvCharger | **주력** · 수 분 주기 스냅 |
| 교통 소통 | 대구 소통정보 등 | 보조 |
| 돌발(UTIC) | UTIC | 조인 보조 · 신규 적재 제약 → KPI FAIL·HOLD |
| 경로 ETA | TMAP | 학습 라벨·피처용 (학습 origin=동대구역 고정) |
| 주차 | Team5 등 | 보조 · realtime 커버 얇음 → 점수 금지 |
| 관광 등 | TourAPI | 공간 조인 보조 |

인증키는 `.env` (`DATA_GO_KR_KEY`, `TMAP_APP_KEY` 등). 코드·문서에 키를 넣지 않는다.

## 수집 규모 (최종 컷)

| 항목 | 값 |
|---|---|
| 상태 구간 | 2026-07-17 ~ 2026-08-09 07:23 |
| 최종 pull | `from_lightsail_20260809_072742` |
| 상태 스냅샷 | 약 **2,960**장 |
| 현재표 | **4,210** 충전소 (as_of `2026-08-09T07:23:21+09:00`) |
| 시간표 | 약 **9.12M** 행 |

실수집만 쓴다. 목(mock) JSON·CSV는 쓰지 않는다.

---

## 수집에서 겪은 주요 이슈

1. **페이지 경계 중복**  
   같은 `(statId, chgerId)`가 여러 번 올 수 있다 → 읽을 때 `statUpdDt` 최신만 유지.

2. **일 트래픽 한도**  
   EvCharger 기준 약 1,000건/일 → 개발 중 불필요 반복 호출 금지. KPI상 당일 호출 예: **178/1000 (OK)**.

3. **갱신이 느린 충전소**  
   as_of 기준 CHECK(>15분)가 다수인 것은 **수집 파이프 고장**이 아니라 원천 갱신 특성. 5/15분 기준은 완화하지 않음.

4. **UTIC·주차**  
   IP·키·커버 한계 → 문서화 후 **주력 점수에서 제외/HOLD**.
