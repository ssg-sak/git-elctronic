# 05. 테이블·계약·연동 경계

| 대응 미팅 항목 | **5~8** (백엔드 연동 · DB/테이블 · REST · FE–BE) |
|---|---|
| 발표·면접 | **①이 제공하는 표·필드·흐름**만 · API/화면 구현은 BE·FE |

REST URL·프론트 컴포넌트를 “내가 구현했다”고 말하지 않는다.  
말할 것: **어떤 테이블이 들어가고, 요청이 오면 데이터가 어떻게 붙는지.**

---

## 6에 해당하는 것 — 서비스용 데이터 테이블 (① 산출)

팀에서 DB라고 부를 때, ①이 만든 **논리 테이블(데이터셋)**은 다음이다.

| 이름(쉬운 말) | 파일/ID | 행 단위 | 용도 |
|---|---|---|---|
| **현재표** | `station_feature_snapshot` (D1) | 충전소 1행 | 추천 **입력** (지금 as_of) |
| **시간표** | `station_feature_panel` (D2) | 충전소 × 시각 | 학습·시계열 피처 |
| **도착 라벨** | arrival labels (+derived) | 학습 행 | 타겟 `target_available_at_arrival` |

경로 예:

- 현재표: `apps/data-pipeline/evaluation/results/datasets/station_feature_snapshot_latest.*`
- 시간표: `.../station_feature_panel_latest.parquet`

스키마 정본: `docs/data/스키마/` (`데이터셋_명세.md`, `피처_카탈로그.md`, `추천입력_계약_v1_제안.md`)

### 현재표에 들어가는 핵심 컬럼 (요약)

| 컬럼 | 의미 |
|---|---|
| `statId` | 충전소 PK |
| `as_of_ts` | 기준시각 |
| `lat`, `lng`, `coord_ok` | 좌표·유효 |
| `total_chargers`, `available_count` | 대수·가용 수 |
| `availability_ratio_observed` | 관측 가용률 |
| 신선도·관측 관련 | age, freshness, unobserved 등 |

## 5에 해당하는 것 — “요청하면 어떤 결과가 나오나” (데이터 층)

추천 API의 **점수 숫자**는 ②·BE가 만든다.  
① 기준으로 흐름만 정리하면:

```
[사용자 요청] 위치 · 차량 · SOC 등
        │
        ▼
[백엔드] TMAP ETA·거리 결합 · 현재표(as_of) 로드
        │
        ▼
[DA② 점수] 피처 → 점수·위험도·Top-N
        │
        ▼
[응답] 추천 목록 (+ 신선도 경고 등)
```

①이 **미리 준비해 두는 결과물**:

| 입력(준비) | 출력(표) |
|---|---|
| 상태 스냅 CSV들 | 현재표 1행/소 · 신선도·가용·대수 |
| 스냅 시계열 | 시간표 · lag 피처 원천 |
| TMAP ETA(학습) | 라벨·`tmap_eta_min` |

①이 **요청마다 안 하는 것**: 실시간 HTTP 추천 응답 생성.

### DA① → 백엔드/② 넘기는 필드 (계약 요약)

| 필드 예 | 의미 |
|---|---|
| `station_id`, `as_of` | 어떤 소 · 어느 시각 기준 |
| `available_count`, `observation_coverage` | 관측 가용 |
| `freshness_flag` / 신선도 | FRESH·AGING·CHECK·UNOBSERVED |
| `recheck_required` | stale·미관측·가용 1대 이하 등 |
| `data_quality_flags` | 품질·제외 사유 (점수에 숨기지 않음) |
| `availability_guaranteed` | 예약 없으면 항상 `false` |

백엔드가 **요청 시점**에 붙이는 것: 차량·SOC·**사용자 위치 TMAP ETA**·경로 거리.

학습 때 ETA origin은 동대구역 고정 → **서빙과 다름**을 문서에 명시했다.

## 7·8에 해당하는 것 — REST·FE 연동에서 ①이 말할 범위

| 말함 | 안 말함(넘김) |
|---|---|
| 추천 입력은 현재표 + 요청 ETA | 엔드포인트 경로·상태코드 설계 전부 |
| 오래된 상태는 CHECK 플래그로 전달 | React 화면 컴포넌트 |
| 스키마·계약 문서 위치 | FastAPI 라우터 구현 디테일 |
