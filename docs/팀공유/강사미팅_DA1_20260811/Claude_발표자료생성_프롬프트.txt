# Claude에게 보낼 프롬프트 (이 파일을 열어 아래 박스 전체를 복사)

첨부 zip(또는 이 폴더)을 읽고, AI·데이터 ①(이현석) 역할에 맞는 발표자료를 만들어 주세요.

---

너는 EV SafeCharge 프로젝트의 발표자료 작가다.
첨부한 폴더/파일을 근거로만 작성하고, 없는 숫자는 만들지 마라.

## 발표자 역할 (절대 지킬 것)
- 담당: AI·데이터 ① — 데이터 수집 반영, 전처리, 현재표/시간표, EDA·KPI, 스키마, 도착 라벨, 최종 9피처, HOLD 문서
- 담당 아님: 추천 점수, Top-N, REST API, 프론트, 운영 모델 서빙 (그건 ②·BE·FE)
- 상태 코드: DA1_READY_FOR_DA2_MODEL_EVALUATION
- 용어: D1/D2 대신 "현재표"/"시간표"
- 미관측 ≠ 고장
- HGB/PR-AUC = 피처 적합 점검이지 서비스 성능 확정 아님

## 만들어 줄 산출물 (한 번에)
1) 노션용 발표 본문 (마크다운, 제목·표·불릿, 복붙 가능)
2) 슬라이드 15장 구성 (장마다: 제목 / 화면에 보여줄 것 / 말할 말 2~4문장)
3) 강사 예상 질문 8개 + 짧은 답
4) 시연 순서 (어떤 파일을 어떤 순서로 열지 — 첨부 경로 기준)
