# 클로드 현장 규칙

강사님 앞에서 Claude를 쓸 때.

## 해도 됨

- 질문 듣고 **답 초안** 받기
- 컬럼·그림 **한 줄 해석** 다시 받기
- 다음 시연 파일 경로 물어보기
- 내 말을 30초로 다듬기

## 하지 말 것

- Claude 답을 **그대로 낭독** (훑고 내 말로)
- “AI가 이렇게 말했습니다”를 앞에 세우기
- ① 범위를 넘는 구현을 Claude에게 시키며 시간 쓰기
- 없는 수치를 Claude가 지어내게 두기 → “파일 열어라”로 돌리기

## 추천 워크플로

```
강사 질문
  → 프롬프트모음에서 블록 복사
  → Claude 답 (5~15초)
  → 내가 확인 후 강사에게 말하기
  → 필요하면 보여줄_데이터 파일 열기
```

## Cursor에서 쓸 때

1. 채팅에 `00_컨텍스트_붙여넣기` 먼저  
2. `@보여줄_데이터/10_자료별_해설.md` 등 **파일 언급** 가능하면 붙이기
