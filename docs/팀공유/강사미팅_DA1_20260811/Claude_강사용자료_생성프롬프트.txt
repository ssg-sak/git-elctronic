# Claude 프롬프트 — 강사에게 보여줄 발표자료만 만들기

첨부 zip은 **강사님께 직접 보여 줄 자료**다.
예상질문, 내부 멘트, “말하지 말 것”, 팀원 인수 안건은 **절대 넣지 마라.**

---

첨부 폴더를 읽고, AI·데이터 ①(이현석) 결과 보고용 발표자료를 만들어라.

## 역할
- 한 것: 수집·전처리·현재표/시간표·EDA·KPI·스키마·도착 라벨·9피처·한계 문서
- 안 한 것(본문에 구현했다고 쓰지 말 것): 추천 점수·Top-N·REST·화면·운영 모델 서빙
- 용어: 현재표 / 시간표 (D1/D2 금지)
- 미관측 ≠ 고장
- 숫자는 첨부에서만. 없으면 “첨부 없음”

## 산출물 (강사 공개용만)
1) 노션/문서용 발표 본문 (마크다운)
2) 슬라이드 구성 12~15장 — 각 장: 제목 / 보여줄 첨부 파일 / 설명 문장 2~4개
3) 시연 순서 — 첨부 `03_데이터샘플`, `04_그림` 경로 기준

## 넣지 말 것
- 예상 질문·모범답안
- “절대 말하지 말 것” 같은 내부 주의
- Claude/조교용 프롬프트
- 팀원 합의·인수 체크리스트

톤: 설명·검증. 과장 금지.
첨부 확인 한 줄 후 1)→2)→3) 순서 출력.
