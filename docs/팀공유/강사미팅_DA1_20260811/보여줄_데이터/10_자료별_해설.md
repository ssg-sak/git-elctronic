# 자료별 해설 — 강사 시연용

이 파일을 **옆에 두고** CSV·PNG를 연다.  
각 항목: **무엇인가 → 무엇을 보면 되나 → 한 줄 해석 → 오해 주의**

공통 가용률:

```
가용률 = 사용가능 / (사용가능 + 사용중)
```

미관측·고장·점검은 분모 제외. 미관측 ≠ 고장.  
점수·Top-N은 이 자료에 **없음** (DA②).

### 1-1. `01_현재표_한글컬럼/현재표_미리보기_30행_한글컬럼.csv` ★

| | |
|---|---|
| **무엇인가** | 기준시각 한 시점의 **충전소 1행** 요약 (시연용 30행) |
| **무엇을 보면** | `사용가능_대수`, `관측_가용률`, `상태신뢰도_등급`, `확정가용_여부` |

| **오해 주의** | 추천 점수 열이 없다. 도착 시 보장을 의미하지 않는다. |
