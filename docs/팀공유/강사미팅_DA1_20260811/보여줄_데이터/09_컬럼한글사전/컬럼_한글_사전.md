# 컬럼 한글 사전 (강사 시연용)

영문 헤더 ↔ 우리말. 시연 CSV는 `01_현재표_한글컬럼/`, `02_라벨_한글컬럼/` 사용.

---

## 현재표 (핵심 컬럼)

| 영문 | 한글 | 뜻 |
|---|---|---|
| `statId` | 충전소ID | 충전소 고유 ID |
| `as_of_ts` | 기준시각 | 이 표를 찍은 “지금” |
| `available_count` | 사용가능_대수 | 관측상 사용 가능(stat=2) 대수 |
| `total_chargers` | 전체_충전기수 | 등록 충전기 수 |
| `availability_ratio_observed` | 관측_가용률 | 가능/(가능+사용중) |
| `reliability_grade` | 상태신뢰도_등급 | 상태갱신 기준 신선도 |
| `observation_grade` | 관측신선도_등급 | 우리가 관측한 시각 기준 |
| `coord_ok` | 좌표_유효 | 좌표 품질 OK |
| `has_confirmed_available` | 확정가용_여부 | 사용가능 ≥ 1 |
| `lat` / `lng` | 위도 / 경도 | 좌표 |
| `unobserved_rate` | 미관측_비율 | 상태를 못 본 비율 |
| `status_age_minutes` | 상태경과_분 | 상태 변경 후 경과 |
| `observation_age_minutes` | 관측경과_분 | 마지막 관측 후 경과 |

### 등급 한글

| 영문 | 한글 |
|---|---|
| `HIGH` | 높음(5분이내) |
| `NORMAL` | 보통(5~15분) |
| `CHECK_REQUIRED` | 확인필요(15분초과) |
| `UNOBSERVED` | 미관측 |

## 도착 라벨 (핵심)

| 영문 | 한글 | 뜻 |
|---|---|---|
| `statId` | 충전소ID | |
| `feature_as_of` | 피처_기준시각 | 피처를 읽은 시각 |
| `target_time` | 도착예상_시각 | as_of + ETA |
| `matched_arrival_time` | 매칭된_패널시각 | 패널에서 맞춘 시각 |
| `horizon_minutes` | 예측_시차_분 | |
| `tmap_eta_min` | TMAP_이동시간_분 | 학습용 ETA |
| `origin_id` | 출발지ID | 학습은 `동대구역(학습고정)` |
| `current_available_count` | 출발시_사용가능_대수 | |
| `arrival_available_count` | 도착시_사용가능_대수 | |
| `target_available_at_arrival` | 도착시_가용여부_타겟 | 가능/불가 |
