## 1. 표준 상태 (역할 정의)

| 표준(한글) | 영문 코드 (권장) | 의미 |
|---|---|---|
| 사용 가능 | `AVAILABLE` | 충전 대기·이용 가능 |
| 사용 중 | `IN_USE` | 충전 중 (`CHARGING`과 동일 취급) |
| 고장 | `OUT_OF_ORDER` | 운영 중지 등 사용 불가(고장·중지) |
| 점검 | `UNDER_INSPECTION` | 점검 중 |
| 미확인 | `UNKNOWN` | 통신이상·상태미확인·미관측·미매핑 |

> 서비스·피처·데이터셋에서는 **표준 5값**만 쓴다. 원천 코드는 원본 컬럼(`stat` / `stat_raw`)에 보존.

## 2. EvCharger 원천 → 표준

| 원천 `stat` | API 관례 의미 | 표준(한글) | 영문 코드 | 비고 |
|---|---|---|---|---|
| `1` / `01` | 통신이상 | 미확인 | `UNKNOWN` | 사용 가능 여부 확정 불가 |
| `2` / `02` | 충전대기 | 사용 가능 | `AVAILABLE` | |
| `3` / `03` | 충전중 | 사용 중 | `IN_USE` | 별칭 `CHARGING` 허용 |
| `4` / `04` | 운영중지 | 고장 | `OUT_OF_ORDER` | |
| `5` / `05` | 점검중 | 점검 | `UNDER_INSPECTION` | |
| `9` / `09` | 상태미확인 | 미확인 | `UNKNOWN` | |
| (값 없음·조인 실패) | 미관측 | 미확인 | `UNKNOWN` | **≠ 고장**. `status_missing`/`UNOBSERVED` 플래그 병행 |
| 그 외 | 미매핑 | 미확인 | `UNKNOWN` | `UNKNOWN_CODE` 로그 권장 |

## 3. 집계·피처 규칙 (표준화 후)

| 규칙 | 내용 |
|---|---|
| 미관측 | `UNKNOWN`이지만 **고장/점검을 늘리지 않음**. 가용률은 관측분 분모 또는 패널 정의 사용 |
| 사용 가능 대수 | 표준=`AVAILABLE` 인 충전기 수 |
| 사용 중 대수 | 표준=`IN_USE` |
| 고장·점검 대수 | `OUT_OF_ORDER` + `UNDER_INSPECTION` |
| 신뢰도 | `statUpdDt` 경과시간 (루트 `AGENTS.md`: 5분/15분). 상태 코드와 별개 |

## 6. 공식 API 4값 (데이터파트_작업가이드)

목데이터·`json/charger-status-history.json`·DA➁ 초기 연동은 **4값**을 사용한다.

| 공식 API | 내부 5값으로 펼치기 |
|---|---|
| `AVAILABLE` | `AVAILABLE` |
| `CHARGING` | `CHARGING` / `IN_USE` |
| `OUT_OF_SERVICE` | `OUT_OF_ORDER` + `UNDER_INSPECTION` + 통신이상(`1`) |
| `UNKNOWN` | `UNKNOWN` · 미관측 |

코드: `processing/status_standard.py` · `processing/export_history_json.py`
