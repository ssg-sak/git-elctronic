## 4. 시계열 확장 (status 누적 후)

| 피처 | 정의 | 소스 |
|---|---|---|
| `avail_rate_lag_15m` | 같은 세그먼트에서 **달력 기준 ~15분 전** `availability_ratio_observed` (창: `[t−27m, t−15m]`). 행 shift 아님. 없으면 null | D2 패널 |
| `avail_rate_lag_60m` | 동일 규칙 **~60분 전** (창: `[t−75m, t−60m]`) | D2 패널 |
| `obs_count_charger` | 충전기 누적 관측 횟수 | index/snapshots |

- null 정책: 세그먼트 초반·공백 직후·창 안 틱 없음 → null (0으로 채우지 않음).
- 정본 상세: [`데이터셋_명세.md`](./데이터셋_명세.md) §3 lag 정의.
- 기준시각·행 단위: 동일 문서.
