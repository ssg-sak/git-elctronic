## 추천 티어

### A. MVP 기본 (먼저 이것만) — 과적합 상대적으로 낮음

도메인 필수 + 단변량 강함 + 8/3→8/4 (판정 변화 0) 안정.

| 피처 | AUC | 이유 |
|---|---:|---|
| `available_count` | 0.82 | 최강 신호 · 도착 성공의 핵심 proxy |
| `total_chargers` | 0.72 | 규모·대기 완충 (실패위험 보조와도 정합) |
| `observation_age_minutes` | 0.57 | 신뢰도/신선도 · 가중치 계약과 맞춤 |
| `observation_coverage` | 0.63 | 관측 품질 게이트 |
| `horizon_minutes` | 0.54 | 도착 시차 자체 · AUC는 낮아도 **필수 조건** |
| `known_charger_count` | 0.62 | 라벨 가능 범위와 맞춤 |

> `available_count`는 타겟과 개념적으로 가깝다. **맞는 피처**이지만, 이것만으로 점수를 끝내지 말고 ②가 시간 분할 ablation으로 “미래 예측력”을 확인할 것.

### B. 후보 1개만 추가 (A와 강하게 겹침 주의)

| 피처 | AUC | 과적합 주의 |
|---|---:|---|
| `minutes_since_last_change` | 0.71 | 고유값 많음(고카디널리티) · 트리에 과분할 위험 → **binning/캡** 권장 |
| `usable_count` | 0.67 | `available_count`·`known_*`와 다중공선 · **둘 중 하나** |
| `direct_observed_count` | 0.63 | 위와 동일 묶음 · A에 이미 coverage 있으면 후순위 |

**권장:** A + (`minutes_since_last_change` **또는** `usable_count` 중 1개).  
한꺼번에 available/usable/known/direct를 전부 넣지 말 것.

### C. 기본 세트에 넣지 말 것 (과적합·허위 유의 위험)

| 피처 | 판정 | 이유 |
|---|---|---|
| `sessions_per_charger`, `usage_daytype_avg`, `history_observed` | HOLD_SPARSE | **결측 ~93%** · 있는 행만 보면 AUC 나와도 일반화 위험 큼 |
| `hour`, `weekday`, `is_weekend` | HOLD | AUC≈0.50–0.55 · n커서 q만 작음 · 시간 분할 전엔 보류 |
| `available_count_delta_1tick` | HOLD | 호라이즌 방향 불안정 |
| `direct_observation_coverage` | HOLD | 단변량 약함 · coverage와 중복 |
| `unobserved_rate` | EXCLUDE | `observation_coverage` 완전 여집합 |

주차 realtime / 요금 / ETA / lat·lng → **점수 피처 금지** (기존 계약).  
좌표 유의성(오늘 재실행): `위경도_피처유의성_20260803.md` · AUC≈0.52 → **DO_NOT_ADD**.

## ②에게 넘기는 “최적” 제안 (한 세트)

```text
MVP_v1 features =
  available_count,
  total_chargers,
  known_charger_count,
  observation_coverage,
  observation_age_minutes,
  horizon_minutes
  + [optional one] minutes_since_last_change   # cap/bin 권장
```

**넣지 말 것 (1차):** usage 이력 3종 · 요일/주말 · delta_1tick · unobserved_rate · 주차/요금 · **`eta_is_proxy`(학습입력)**.

**도착 라벨용 파생 (2026-08-06 검토):**  
[`파생변수_검토_도착라벨_20260806.md`](../파생변수_검토_도착라벨_20260806.md) —

제외: 여유충전기 · 경과×ETA. 보류: 가용비율 · 오래됨/미관측 플래그.

**필수 검증 (과적합 가드):**  
시간 기준 out-of-sample ablation · 캘리브레이션 · (가능하면) 충전소 그룹 홀드아웃.

## 왜 이게 “최적”인가

1. 단변량에서 실용 AUC·CI·호라이즌 안정을 통과한 것 위주  
2. 상관 묶음은 대표 1~2개만 → 분산 팽창·과적합 완화  
3. 희소·약한 시간 피처는 “유의해도” 보류  
4. 7/29와 판정 동일 → 데이터 늘어나도 세트가 흔들리지 않음  

최종 모델·가중치는 ②. 이건 **입력 세트 추천**이다.

