# 03. 전처리 파이프라인

원본 CSV는 불변. 읽는 쪽·산출 표만 만든다.

## 순서

1. **중복 제거** — `(statId, chgerId)` 최신 `statUpdDt`  
2. **상태 매핑** — EvCharger `stat` 숫자 → 표준 5값  
3. **gap-safe 패널** — 스냅 간격 **25분 초과** 시 구간 끊고 ffill  
4. **충전소 집계** — 가용률 = 가능/(가능+사용중)  
5. **현재표 as_of** — `statUpdDt ≤ as_of` · 신선도 등급 · `coord_ok`

## 상태코드 매핑

| 원천 `stat` | 의미 | 표준 |
|---|---|---|
| 1 | 통신이상 | 미확인 `UNKNOWN` |
| 2 | 충전대기 | 사용 가능 `AVAILABLE` |
| 3 | 충전중 | 사용 중 `IN_USE` |
| 4 | 운영중지 | 고장 `OUT_OF_ORDER` |
| 5 | 점검중 | 점검 `UNDER_INSPECTION` |
| 9·없음 | 미확인·미관측 | `UNKNOWN` (≠고장) |

정본: `docs/data/스키마/상태코드_매핑.md`
