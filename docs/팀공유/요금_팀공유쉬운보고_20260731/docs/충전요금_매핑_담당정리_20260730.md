## 왜 백엔드가 먼저인가 (재확인)

| 이유 | 이번 파일로 보는 근거 |
|---|---|
| **시점 의존** | 한전 표가 경/중/최대부하 단가 → **요청 시각** 필요 |
| **화면/API** | “지금 얼마/kWh”는 응답 필드 |
| **전소 키 없음** | CHA ON은 1소, 한전 표는 요금제명만 → 모델 학습 라벨로 부적합 |
| **운영사 다양** | 대구 info `busiId` 68종. GS차지비·파워큐브 등은 한전 표에 없음 → BE가 CPO별 정책/캐시 |
