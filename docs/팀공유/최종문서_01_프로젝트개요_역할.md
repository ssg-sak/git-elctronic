## 서비스 목표 (데이터 관점)

EV SafeCharge는 “가까운 충전소”가 아니라 **도착했을 때 충전 가능할 가능성이 높은 충전소**를 고른다.  
이를 위해 실시간 상태, 갱신 신선도, 시간대 가용 패턴, 학습·규칙용 표 입력이 필요하다.

## ①이 한 것 / 안 한 것

| 한 것 | 안 한 것 (②·BE·FE) |
|---|---|
| 수집·품질·전처리 | 추천 점수·Top-N |
| 현재표·시간표 | REST API·화면 |
| EDA·KPI·스키마·한계 | 모델 서빙 |

학습 ETA는 **동대구역 고정**. 서빙은 **사용자 위치 TMAP**.
