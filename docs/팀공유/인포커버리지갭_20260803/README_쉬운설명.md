## 왜 우려가 맞나
1. EvCharger는 **등록·노출된 충전기**만 담음 (단지 내부 미등록/지연 등록 가능)
2. 입주자 전용·운영사 앱 전용은 공공 목록에 늦거나 안 뜰 수 있음
3. 이름 불일치(관리사무소/운영사명)로 **있어도 못 찾을** 수 있음
4. status는 변경분이라 info에 있어도 관측이 비는 경우가 많음
