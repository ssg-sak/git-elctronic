## 30초 요약

1. **초록(공용)** → 밤에도 대략 **60%대** 여유  
2. **빨강(아파트·이용제한)** → 낮에 비고 / **밤에 붐빔 (~20%대)**  
3. “밤이면 다 힘들다”는 **아파트가 평균을 깎아서** 그렇게 보인 것에 가까움  
4. 추천 볼 때는 **공용(초록)** 기준
