## 2. 개방데이터 준수사항 (전원 필수)

UTIC 신청 시 동의한 조건입니다. **①만의 규칙이 아니라 서비스 전체**에 적용됩니다.

| # | 준수 | 팀에서 어떻게 |
|---|---|---|
| **①** | 신청 **목적 외 사용 금지** | EV 충전 추천 MVP·연구만. 다른 과제·재판매·재배포 금지 |
| **②** | **출처 표기** | UI·문서·API 메타에 「경찰청 도시교통정보센터(UTIC)」 |
| **③** | **효력 1년** (미거절 시 연장) | 승인일 기록 · **만료 30일 전** 점검 |
| **④** | 미준수 시 **제공 중단** | 위반 의심 시 즉시 UTIC 호출 중단 → 팀 공유 |

상세·문구 예시: [`UTIC_개방데이터_준수사항.md`](../data/API/UTIC_개방데이터_준수사항.md)

### 표기 (프론트·백엔드 합의용 초안)

| 위치 | 문구 초안 |
|---|---|
| 앱/웹 (돌발·교통 표시 시) | `교통정보: 경찰청 도시교통정보센터(UTIC)` |
| API 메타 | `traffic_data_source: "UTIC"` |
| 데이터셋 플래그 | `traffic_source=utic` |

문구 확정은 **프론트·백엔드**가 한 번 맞춰 주시면 됩니다.

## 3. 역할별 요청

| 담당 | 요청 |
|---|---|
| **AI·데이터 ①** | 대구 필터 CSV · 공간조인 · D1 `traffic_is_mock=false` · 소통 프로브 |
| **AI·데이터 ②** | 점수·위험도에 UTIC 피처 쓸 때 **출처 메타 유지** · raw XML을 모델 산출물에 넣지 않음 |
| **프론트** | 교통/돌발 UI에 **출처 표기** (§2 초안) |
| **백엔드** | 추천·충전소 상세 응답에 `traffic_data_source` (또는 동등 필드) |
| **수집** | 공식 스케줄에 UTIC 넣을지 · **AWS IP** UTIC 등록 여부 → ①과 합의 |
| **전원** | 키를 채팅·PR·이슈에 붙이지 않기 · `.env`만 |
