## 0. 쓰는 법 (30초)

1. 그림 파일명(01, 02…)을 찾는다  
2. 아래 **「읽는 법」** → **「이렇게 말하면 됨」** → **「착각 금지」** 순으로 본다  
3. 숫자 근거가 필요하면 각 폴더의 `summary.json` / CSV를 연다  

**공통 원칙**

| 원칙 | 뜻 |
|---|---|
| 패널 가용률 | 그 시각 **도시(또는 집단) 전체**에서 관측된 충전기 중 빈 비율 |
| 날짜 구멍 | 수집 안 한 시각 → 히트맵 **회색**. 가용률 0%가 아님 |
| STALE 많음 | EvCharger 갱신 느림이 흔함 → **파이프라인 고장 아님** |
| 주차/요금 그림 | 보조·게이트용. **점수에 넣지 말라는 신호**일 수 있음 |

## 2. 시간대 가용률 (`시간대_가용률_*`)

스크립트: `plot_and_reliability_all_snapshots.py`

### 01 — 패널 가용률 시계열

| | |
|---|---|
| **무엇을** | 스냅마다 “그 순간 도시 패널 가용률(%)”을 시간에 따라 그림 |
| **읽는 법** | 위로 갈수록 빈 충전기 비율↑. 점선=전체 평균 |
| **이렇게 말하면** | “수집 기간 동안 도시 가용률이 이렇게 오르내렸다” |
| **착각 금지** | 특정 충전소 한 곳 그래프가 아님. 끊긴 구간=수집 공백일 수 있음 |

### 02 — 틱 간격(갭) 분포

| | |
|---|---|
| **무엇을** | 스냅 사이 시간 간격이 얼마나 벌어졌는지 |
| **읽는 법** | 대부분 ~10분이면 루프 정상. 25분 초과는 gap-safe 패널이 **안 이어 붙이는** 구간 |
| **이렇게 말하면** | “수집 리듬이 안정적인지 / 큰 구멍 횟수” |
| **착각 금지** | 갭 ≠ 충전기 고장 |

### 03 — 일자별 스냅 수 · 일자별 평균 가용률

| | |
|---|---|
| **무엇을** | 날짜마다 몇 장 찍었는지 + 그날 평균 가용률 |
| **읽는 법** | 막대 낮음=그날 수집 적음. 가용률 막대와 함께 보면 “표본 적은 날” 구분 |
| **이렇게 말하면** | “어느 날이 두껍게/얇게 쌓였는지” |
| **착각 금지** | 스냅 수 적다고 그날 도시가 비었다는 뜻 아님 |

### 04 — 시간대×일자 히트맵

| | |
|---|---|
| **무엇을** | 가로=시, 세로=날짜, 색=가용률. **회색=미수집** |
| **읽는 법** | 밝은/어두운 띠=시간대 패턴. 회색 덩어리=그 날짜·시각 데이터 없음 |
| **이렇게 말하면** | “언제 구멍이 있는지 + 언제 여유인지 한눈에” |
| **착각 금지** | 회색을 0% 가용으로 읽지 말 것 |

### 05 — 신뢰도 등급 (fetched − statUpdDt)

| | |
|---|---|
| **무엇을** | 상태 정보가 얼마나 신선한지 등급 분포 |
| **읽는 법** | HIGH≤5분 / NORMAL≤15분 / CHECK>15분 (AGENTS 규칙) |
| **이렇게 말하면** | “지금 UI에 ‘확인 필요’가 많을 수 있는 이유” |
| **착각 금지** | CHECK/STALE 많음 ≠ D1 빌드 실패. 등급 기준 완화 금지 |

### 06 — 일자별 신뢰도 구성

| | |
|---|---|
| **무엇을** | 날마다 HIGH/NORMAL/CHECK 비율 쌓은 그림 |
| **읽는 법** | CHECK 비율이 치솟는 날=그날을 자세히 볼 후보 |
| **이렇게 말하면** | “신선도가 날짜마다 어떻게 달랐는지” |
| **착각 금지** | 하루 CHECK↑만으로 전체 파이프라인 폐기 판단 금지 |

### 07 — 충전소 관측 커버리지 맵

| | |
|---|---|
| **무엇을** | 지도 위 충전소가 관측/미관측에 가깝게 찍힌 분포 |
| **읽는 법** | 점이 모인 곳=대구 중심 관측. 빈 곳=마스터엔 있으나 스냅에 약함 |
| **이렇게 말하면** | “공간적으로 어디를 보고 있는지” |
| **착각 금지** | 맵에 없다고 그 지역 추천 불가라고 단정하지 말 것 (UNOBSERVED 정책) |

### 08 — 시간대 합집합 프로파일 ★자주 질문

| | |
|---|---|
| **무엇을** | 날짜 구멍 무시하고 **같은 시(0~23)** 끼리 모아 평균·중앙값 |
| **읽는 법** | 초록=평균, 파랑=중앙값, 회색=그 시각 틱 수. 보통 **낮↑ 밤↓** |
| **평균 < 중앙값** | 대부분 날은 비슷, **가끔 확 낮은 날**이 평균만 끌어내림 → [전용 해설](./시간대_가용률_평균중앙값_해설_20260731.md) |
| **이렇게 말하면** | “보통 그 시각엔 중앙값, 보수적으로 보면 평균” |
| **착각 금지** | “실시간 갱신 충전소가 적다”로 해석하지 말 것 |

### 09 — 공용 vs 주거·이용제한 시간대

| | |
|---|---|
| **무엇을** | 집단별로 시간대 가용률 곡선 비교 |
| **읽는 법** | 공용 곡선이 추천 후보에 더 가깝다. 주거/제한은 참고 |
| **이렇게 말하면** | “누구에게 열려 있는 소인지 나눠 본 시간대 패턴” |
| **착각 금지** | 이름 휴리스틱(아파트 등)은 완벽 분류 아님 |

## 9. 해석 복붙 템플릿

그림 설명할 때:

```text
[그림명]: (한 줄로 무엇을 보는지)
관찰: …
의미: …
하지 말 것: …
다음에 볼 숫자/파일: …
```

예시 (08번):

```text
[08 합집합 프로파일]: 0~23시 도시 가용률의 보통값·평균
관찰: 낮에 높고 밤에 낮음. 중앙값 ≥ 평균인 시각이 많음
의미: 시간대 패턴 유의미. 가끔 낮은 날이 평균만 내림
```
