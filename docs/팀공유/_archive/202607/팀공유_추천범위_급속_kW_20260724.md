## 결정

1. **MVP Recommendation Candidate = 급속 이상만**  
   `is_fast_charger == True` (명목 50kW+ 등 팀 규칙으로 확정)
2. **RAW / CHARGER MASTER에는 완속 보존** — “완속 데이터 삭제” 금지
3. **화면 필터:** 50 / 100 / 200 / 350kW+ (또는 `전체 급속 · 100↑ · 200↑ · 초급속`)
4. **엔티티:** `STATION → CHARGER(kW)`  
   같은 장소를 `OO-100` / `OO-200` 충전소로 **복제하지 않음** (핀·통계 중복 방지)
5. **점수:** 출력은 한 항. `effective_power ≈ min(차량최대kW, 충전기kW)` 후보.  
   **고출력 무조건 가산 금지** (가용·ETA·Busy Risk·신선도가 우선)
