```text
recommend_public_default = true
→ coord_ok = true
→ is_operating_now != "N"
→ observation_state / reliability_grade_effective 로 경고·정렬
→ has_confirmed_available = true  (즉시 충전 가능 탭의 강한 조건)
→ ETA = 백엔드 TMAP (D1 컬럼 사용 금지)
```

## 계약 (반드시)

1. **미관측 ≠ 사용 불가** — `UNOBSERVED` / `observed_count=0`을 곧바로 탈락시키지 말 것.  
2. **주차** — 점수·순위 반영 금지. 게이트 재실행 후 ①과 합의.  
3. **소통 링크** — 도시/주변 맥락. TMAP 경로 ETA와 혼동 금지.  
4. **점수·실패위험도·추천 이유** — ② 영역 (D1에 없음).  
5. **D1 재빌드 as_of** — ①은 핸드오프용으로 `latest-snap` 사용. 라이브 API는 요청 시각(`now`) 기준으로 ②/백엔드가 신선도를 다시 봄.
