## 1. 신선도 (STALE이 많은 이유)

| 질문 | 답 |
|---|---|
| 지금 기본이 `latest-snap`인가? | **예.** D1 빌드 기본값이 `--as-of latest-snap` |
| STALE이 많은 게 고장인가? | **아니오.** 공공 API가 15분 안에 안 바뀌는 충전기가 원래 많음 |
| 팀은 뭘 하면 되나? | Lightsail **pull 직후** D1 돌리기 (기본값 그대로면 됨) |
| 하면 안 되는 것 | STALE을 없애려고 등급 기준(5분/15분)을 느슨하게 바꾸기 |

## 팀원이 기억할 하루 루틴

```text
1) Lightsail pull (로컬 status/교통 루프는 끈 상태)
2) (있으면) Team5 주차 · UTIC
3) D1 빌드  ← 기본 latest-snap
4) 팀 공유 / 조장(DA②) 핸드오프
```

---

## ①이 하는 일 / 안 하는 일

| ① (데이터) | ②·백엔드 |
|---|---|
| D1/D2 재료, 신선도 등급, 주차·돌발·소통 **보조** | 최종 추천 점수, 실패 위험도 |
| `eta_minutes` null 예약 | TMAP으로 ETA 채움 |
| 주차 점수 게이트 판정 | 게이트 PASS 후에만 점수 반영 논의 |

질문이 있으면 DA①에게 “D1 latest / 주차 게이트 / 링크조인” 키워드로 물어보면 됩니다.
