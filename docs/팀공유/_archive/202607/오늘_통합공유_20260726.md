# 7/26(일) 데이터 통합 작업 공유

## 한 줄 요약

오늘은 충전소 상태·도시 혼잡·UTIC 돌발·주차·D1 자료를 다시 맞추고, 팀이 바로 볼 수 있는 그림·품질 점검·전달 자료를 갱신했습니다.

## 오늘 갱신한 것

- **충전소 상태·도시 교통:** Lightsail 서버에서 상태 스냅샷 40개, 교통 파일 52개를 추가로 받았습니다.
- **D1:** 20:45 KST 기준으로 다시 만들었습니다. 충전소 4,210개가 한 행씩 들어 있습니다.
- **가용률·혼잡 그림:** 최신 상태 1,026회, 도시 교통 359회 기준으로 다시 생성했습니다.
- **UTIC 돌발:** 대구 2건, 충전소 54개가 1km 이내 돌발 정보와 연결돼 있습니다.
- **주차:** Team5 PIS 실데이터를 계속 사용합니다. 3,922개 충전소가 1km 이내 주차장과 연결되고, 430개는 realtime 주차 정보도 있습니다.
- **좌표 품질:** 위치가 의심되는 9개 충전소는 추천·지도·거리 계산에서 제외하도록 격리 목록을 만들었습니다.

## 지금 쓸 수 있는 것

- 일반 사용자용 기본 후보: **공용 충전소 1,853개**
- 그중 좌표 정상·확정 가용 후보: **1,371개**
- 공용 후보는 `limitYn` 기준으로 제한 충전소 2,357개와 분리했습니다.
- 주차 거리·UTIC 돌발 거리·과거 이용강도는 값이 있을 때만 보조 정보로 사용합니다.

## 꼭 같이 알아야 할 제한

- D1은 **추천 점수나 ETA를 계산하지 않습니다.** ETA는 백엔드가 TMAP 경로 결과로 채우고, 점수·실패 위험은 모델/서빙 담당이 결정합니다.
- 상태가 없는 것은 “사용 불가”가 아니라 **미관측**입니다.
- 최신 상태 스냅샷은 20:39 KST이며, 충전기 상태 자체의 변경시각이 오래된 경우에는 재확인 경고가 필요합니다.
- UTIC 돌발은 14:12 KST 수집분이라, 사용자에게 실시간 돌발로 보여 주기 전에는 다시 수집해야 합니다.
