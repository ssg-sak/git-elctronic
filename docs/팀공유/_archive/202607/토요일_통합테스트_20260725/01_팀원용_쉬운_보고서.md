# 토요일 쉬운 보고서 — 데이터가 실제 추천 화면까지 갈 수 있나?

## 한 줄 결론

**갈 수 있다.** 충전소 상태, 주차, 돌발, 이용이력 등을 한 충전소 기준으로 합쳤고,
대구시청에서 충전소를 찾는 상황을 넣어 후보와 이유를 실제로 뽑아 봤다.

단, 아직 “이 충전소가 무조건 1등”이라고 계산하는 완성 모델은 아니다.
그 부분은 모델·서빙 담당이 ETA와 최종 점수를 붙여 완성한다.

---

## 오늘 무엇을 연결했나?

```text
충전소 기본정보
  + 지금 사용 가능한 충전기 수
  + 상태가 최근 정보인지
  + 공용으로 쓸 수 있는지
  + 운영 중인지
  + 근처 Team5 주차장·잔여면
  + 근처 UTIC 돌발
  + 과거 이용이 많은 곳인지
  = D1 충전소 통합표
```

각 충전소가 D1에서 한 줄이 된다. 그래서 앱은 한 곳을 보여 줄 때
“몇 대가 비었는지”, “상태를 믿어도 되는지”, “주차장과 돌발은 어떤지”를 함께 보여 줄 수 있다.

---

## 실제로 테스트한 결과

테스트 위치를 **대구시청**으로 두고 후보를 뽑았다.

| 단계 | 남은 충전소 | 뜻 |
|---|---:|---|
| 전체 | 4,210 | 대구 충전소 전체 |
| 공용 후보 | 1,853 | 아파트·제한 시설 등을 기본 추천에서 제외 |
| 공용·좌표 정상·확정 가용 | 1,326 | 지도에 보여 줄 수 있고, 실제로 사용 가능 충전기가 1대 이상 있는 곳 |
| Shadow 테스트 출력 후보 | 1,311 | 운영중지로 확인된 곳까지 제외한 후보 |
| 지금 바로 볼 후보(A) | 255 | 상태가 비교적 최근이고 운영 중으로 확인된 후보 |

예시로 대구시청 자체 충전소는 90m로 가깝고 상태도 최근이지만 충전기가 1대뿐이다.
그래서 화면에는 “가깝다”와 함께 **대기·실패 위험 주의**가 같이 나와야 한다.

이런 식으로 가까운 곳만 보여 주는 게 아니라, 사용자에게 왜 조심해야 하는지도 설명할 수 있다.

## 주차·돌발도 실제로 붙었나?

| 데이터 | 현재 연결 결과 | 어떻게 쓰나 |
|---|---:|---|
| Team5 주차장 거리 | 3,922개 충전소 | 근처 주차장이 있는지 보조 정보 |
| Team5 realtime 주차 | 430개 충전소 | 값이 있을 때 잔여면·점유율 표시 |
| UTIC 돌발 | 최신 조인 266개 충전소 | 근처 사고·공사 경고 보조 |
| 과거 이용이력 | 200개 충전소 | 장기 이용강도 보조 |

값이 없는 경우에는 “0”이나 “사용 불가”라고 바꾸지 않고 **정보 없음**으로 둔다.

## 아직 기다려야 하는 것

- 사용자의 실제 출발지에서 계산한 **ETA(도착시간)**
- 최종 추천 점수와 실패 위험도
- “이 시간에는 보통 비어 있다” 같은 2주 이상 시계열 패턴
- 주차장의 평소 혼잡도

그래서 8월 10일까지 데이터를 더 쌓고, 그때 최신 데이터로 최종 D1·D2를 다시 만든다.
