# 팀이 꼭 알아야 할 쉬운말 설명서

## 먼저 한 줄

우리가 만든 것은 “대구에 충전소가 어디 있나” 목록이 아니다.  
**사용자가 갔을 때 충전할 가능성이 높은 곳을 찾기 위해, 흩어진 정보를 한곳에 모아 둔 준비물**이다.

---

## 어려운 말을 쉬운 말로

| 어려운 말 | 쉬운 말 | 실제 뜻 |
|---|---|---|
| D1 | **충전소 종합 정보표** | 충전소 한 곳마다 현재 상태·주차·이용제한 등을 한 줄로 모은 표 |
| D2 | **충전소 변화 기록표** | 충전소 상태가 시간에 따라 어떻게 바뀌었는지 쌓아 둔 표 |
| snapshot(스냅샷) | **그 순간의 사진** | “지금 이 시각에는 몇 대가 비었나”를 찍어 둔 기록 |
| as_of | **이 정보가 맞는 기준 시각** | 데이터가 언제 기준인지 알려 주는 시간 |
| 신선도 / reliability | **정보를 믿어도 되는 정도** | 최근에 받은 상태인지, 오래된 상태인지 |
| 미관측 | **아직 확인하지 못함** | 사용 불가가 아니라 정보가 없음 |
| ETA | **도착 예상 시간** | 사용자가 출발해서 충전소까지 걸리는 시간 |
| 공간조인 | **지도 위에서 가까운 정보끼리 연결** | 충전소와 주차장·돌발 위치를 거리로 연결하는 작업 |
| Shadow 테스트 | **실서비스 전 리허설** | 실제 점수 없이 후보와 설명이 제대로 나오는지 보는 테스트 |
| STRONG / LIKELY | **확실한 후보 / 가능성 있는 후보** | 충전소가 주차장 안에 있을 가능성의 등급 |

---

## 지금 우리가 할 수 있는 일

앱이 사용자의 위치를 받으면 다음 순서로 충전소 후보를 뽑을 수 있다.

```text
1. 누구나 쓸 수 있는 충전소만 고른다
2. 지도 위치가 정상인 곳만 고른다
3. 실제로 비어 있는 충전기가 있는지 본다
4. 상태 정보가 최근 것인지 확인한다
5. 운영 중인지 본다
6. 근처 주차장·돌발·과거 이용 정보는 보조로 붙인다
```

그래서 단순히 “가장 가까운 충전소” 대신  
**“지금 비어 있고, 정보도 비교적 믿을 만하며, 이용 제한이 적은 충전소”**를 찾을 준비가 됐다.

---

## 꼭 헷갈리지 말 것

### 1. 확인 안 됨은 고장·만차가 아니다

상태를 못 받은 충전소는 **알 수 없음**이다.  
“비어 있지 않다”로 바꾸면 사용 가능한 충전소를 잘못 숨길 수 있다.

### 2. 가까운 주차장이라고 충전소가 그 안에 있는 것은 아니다

주차장과 충전소가 1km 안에 있다고 같은 장소는 아니다.

- **STRONG 55개**: 이름·주소·거리까지 맞아 같은 주차장일 가능성이 높은 곳
- **LIKELY 251개**: 가까워서 가능성은 있지만 확정은 아닌 곳
- **NEARBY_ONLY 238개**: 단순히 주변에 있는 주차장

따라서 주차장 빈자리 정보는 STRONG부터 조심스럽게 사용한다.

### 3. 지금 나온 후보 순서는 최종 추천 순위가 아니다

현재 테스트는 “후보와 이유가 잘 나오는지” 확인한 리허설이다.  
실제 이동시간, 최종 점수, 실패 위험도는 모델·서빙 담당이 완성해야 한다.

---

## 지금까지 확인된 사실

| 내용 | 결과 |
|---|---:|
| 대구 충전소 종합 정보표에 들어간 충전소 | 4,210개 |
| 누구나 쓸 수 있는 기본 후보 | 1,853개 |
| 지도 위치·빈 충전기까지 확인된 공용 후보 | 1,326개 |
| 주차장 안/바로 옆 충전소일 가능성이 높은 주차장 | 55개 |

대구시청을 출발 위치로 넣어 시험했을 때, 충전 가능한 후보와 각 후보의 이유·주의사항이 실제로 출력됐다.

## 8월 10일까지 팀이 같이 해야 할 일

1. **데이터 계속 쌓기**  
   충전기 상태를 계속 모아야 “이 시간에는 보통 비어 있나”를 알 수 있다.

2. **주차장 후보 확인하기**  
   STRONG 55개 중 일부를 지도·주소로 확인해 정말 같은 주차장인지 검증한다.

3. **앱에 보여 줄 말 정하기**  
   “정보가 오래됐어요”, “주차장 정보 없음”, “이용 제한 가능성” 같은 안내 문구를 준비한다.

4. **최종 추천 기능 완성하기**  
   모델·서빙 담당은 이동시간, 최종 점수, 실패 위험도를 붙인다.

## 결론

우리는 이제 여러 데이터를 따로 들고 있는 상태가 아니다.  
**충전소 하나를 설명하고, 후보로 걸러 내고, 왜 추천하거나 조심해야 하는지 말할 수 있는 상태**다.

다만 “언제나 가장 성공할 충전소”를 말하려면 2주 기록과 이동시간·최종 점수 기능이 더 필요하다.
