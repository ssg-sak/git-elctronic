## 1. 우리가 푼 문제

추천 점수 모델을 만드는 게 아니라,

> **도착 시점에 충전 가능할 것 같은가?** (`target_available`)  
> 를 맞추는 데, **지금 갖고 있는 숫자(피처)가 도움이 되는지**를 본다.

도움이 약하거나 과적합하기 쉬운 건 ②에게 “넣지 마라 / 나중에”라고 넘긴다.

## 2. 타겟이 뭔지 (이게 모든 유의성의 기준)

| 라벨 | 의미 |
|---|---|
| **1 (positive)** | 도착 시각(호라이즌 뒤)에 **가용 충전기 ≥ 1** |
| **0 (negative)** | 그때 충전기가 **전부 관측됐고**, 가용은 **0** |
| **제외** | 일부만 관측 → 라벨이 애매해서 학습에서 뺌 |

- 호라이즌: **5 / 10 / 15 / 30분** (도착까지 가정 시간)
- 상태 재구성: 최대 **25분 hold** (빈 틱을 함부로 안 채움)
- 피처는 전부 **`feature_as_of` 시점** 값만 사용 (미래 정보 누수 금지)

오늘 데이터: 학습 가능 행 약 **152만** · train 분할에서 연관 분석 **약 84만** · 충전소 **1,587**.  
positive 비율 ≈ **92.5%** → “그냥 가능하다고 해도” 맞춘 것처럼 보이기 쉬움. 그래서 **정확도만 안 보고 AUC**를 본다.

---

## 3. “유의하다”를 어떻게 정의했나

한 지표만 보지 않는다. n이 크면 p값(유의확률)은 **거의 항상 작아진다.**

| 지표 | 뜻 | 기준 |
|---|---|---|
| **p_value** | “이 피처와 타겟이 무관하다”가 얼마나 말이 안 되나 | 참고 |
| **q_value** | 피처 여러 개 한꺼번에 볼 때 거짓 유의 보정 (BH) | **&lt; 0.05** → 통계적 유의 |
| **directional_auc** | 그 숫자만으로 0/1을 얼마나 갈라내나 (0.5=동전) | **≥ 0.55** → 실용 후보 |
| **blocked_auc** | 날짜 블록을 나눠도 비슷한지 (날짜 외삽에 가까운 체크) | CI와 함께 |
| **auc_ci_low** | AUC 95% 구간 하한 | **&gt; 0.5** → 우연보다 낫다고 보기 |
| **null_rate** | 빈칸 비율 | 높으면 “있는 행만 유의” 함정 |
| **horizon_stable** | 5~30분마다 방향이 비슷한지 | False면 불안정 |

### 티어 (표에 쓴 말)

| 티어 | 조건 | 해석 |
|---|---|---|
| **sig + practical** | q&lt;0.05 이고 AUC≥0.55 | 통계·변별력 둘 다 OK. 그래도 희소/중복이면 HOLD |
| **sig but low AUC** | q&lt;0.05 인데 AUC&lt;0.55 | “숫자는 유의한데 쓸모는 약함” (n 효과) |
| **non-sig** | q≥0.05 | 단변량으로 타겟과 거의 무관 |

→ **유의 ≠ 넣어도 된다.** 유의한데 약한 것·희소한 것이 과적합의 주범이다.

## 5. 좌표(lat / lng) — 이미 있었고, 오늘 다시 확인

### 무엇을 봤나
- `lat`, `lng`
- `dist_from_daegu_center_km` (시청 근처 기준 대략 거리)
- 비교용 baseline: `available_count`, `observation_age_minutes`, `horizon_minutes`

### 오늘 결과 (train)

| feature | dir.AUC | blocked | 판정 |
|---|---:|---:|---|
| `lat` | 0.525 | 0.520 | **DROP_LIKELY** |
| `lng` | 0.527 | 0.527 | **DROP_LIKELY** |
| `dist_from_daegu_center_km` | 0.543 | 0.512 | **DROP_LIKELY** |
| `available_count` (참고) | **0.822** | 0.819 | BASELINE |

p값은 좌표도 매우 작다 (n 효과). 하지만 AUC가 **0.52 근처**라  
“위치가 북쪽/남쪽이라서 도착 가용이 갈린다”고 보기 어렵다.

### 결론
- **모델 입력에 lat/lng 넣지 말 것** (`DO_NOT_ADD`)
- 지도 표시·거리 조인·후보 필터용으로는 **계속 사용**
- 7/31 결론과 **동일** (데이터 늘어도 안 바뀜)
