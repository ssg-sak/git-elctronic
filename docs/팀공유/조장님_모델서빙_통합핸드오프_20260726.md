## 입력 계약

최신 파일:

```text
apps/data-pipeline/evaluation/results/datasets/station_feature_snapshot_latest.csv
```

후보 생성 권장 순서:

```text
recommend_public_default = true
→ coord_ok = true
→ is_operating_now != "N"
→ 상태·신선도·미관측은 경고/등급으로 유지
→ has_confirmed_available = true는 즉시 충전 가능 탭의 강한 조건
→ ETA는 요청 시점 백엔드 TMAP 결과를 결합
```

## 반드시 지킬 해석

| 항목 | 계약 |
|---|---|
| 미관측 | `observed_count=0`과 높은 `unobserved_rate`는 사용 불가가 아니다. |
| 상태 신선도 | `reliability_grade_effective`와 `observation_age_minutes`를 사용자 경고·규칙 입력으로 쓴다. |
| 공용성 | `limitYn=Y`가 하나라도 있으면 기본 공용 후보에서 제외한다. 아파트성 이름은 단독 제외 근거가 아니다. |
| 좌표 | `coord_ok=false` 9개 충전소는 지도·거리·추천 후보에서 제외한다. |
| 주차 | `nearest_parking_m`·잔여면·점유율은 값이 있을 때만 보조 신호다. null은 주차 불가가 아니다. |
| UTIC | `nearest_incident_m`은 보조 신호다. 현재 원천은 14:12 KST 수집분이므로 실시간 표시 전 재수집이 필요하다. |
| 이용 이력 | `history_observed=true`일 때만 `usage_level`을 사용한다. |

## ①이 제공하지 않는 것

- 최종 추천 점수, 실패 위험도, 추천 이유
- 경로별 ETA·실시간 이동시간
- 도착 시점 충전 성공확률 모델
- 주차 혼잡의 시간대 예측

`eta_minutes`는 현재 null 예약 필드입니다. ②는 점수 정책을 정하고, 백엔드는 요청 시점 TMAP ETA를 결합해야 합니다.
