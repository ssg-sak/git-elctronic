# DA① → DA②·백엔드 추천 입력 계약 v1 (제안)

| 항목 | 내용 |
|---|---|
| 상태 | **제안 — DA②·백엔드 확인 필요** |
| 행 단위 | 충전소 1행 × 추천 기준시각 `as_of` |
| 정적·준실시간 제공 | DA① |
| 요청 시점 결합 | 백엔드 |
| 점수·랭킹 | DA② |

---

## 1. 계약 원칙

1. `현재 관측상 가용`과 `도착 시 충전 보장`을 분리한다.
2. `availability_guaranteed`는 예약·점유 잠금 기능이 없는 동안 항상 `false`다.
3. `statUpdDt` 기반 상태 시각과 `fetchedAt` 기반 관측 시각을 분리한다.
4. 차량·SOC·TMAP ETA·경로 거리는 사용자 요청마다 백엔드가 결합한다.
5. DA①의 품질 플래그는 점수에 숨기지 않고 별도 필드로 전달한다.

---

## 2. DA① 제공 필드

| 필드 | 타입 | 의미 |
|---|---|---|
| `station_id` | string | 충전소 ID |
| `as_of` | ISO8601 | D1 추천 입력 기준시각 |
| `status_updated_at` | ISO8601/null | 원천 상태 변경시각 |
| `status_observed_at` | ISO8601/null | AWS 수집기가 해당 상태를 관측한 시각 |
| `status_age_minutes` | number/null | 상태 변경 후 경과시간 |
| `observation_age_minutes` | number/null | 마지막 관측 후 경과시간 |
| `freshness_flag` | enum | `FRESH/AGING/CHECK_REQUIRED/UNOBSERVED` |
| `available_count` | integer | 최근 관측상 가용 충전기 수 |
| `observed_count` | integer | 관측된 충전기 수 |
| `observation_coverage` | number/null | 관측 수 ÷ 전체 충전기 수 |
| `observed_available` | boolean | 최근 관측상 가용 충전기 존재 |
| `static_candidate_ready` | boolean | 공용·좌표·운영·관측 기본 게이트 통과 |
| `recheck_required` | boolean | stale·미관측·가용 1대 이하 |
| `availability_guaranteed` | boolean | 현재는 항상 `false` |
| `data_quality_flags` | string | 품질·제외 사유 목록 |

---

## 3. 백엔드 요청 시점 필드

| 필드 | 필수 | 의미 |
|---|:---:|---|
| `request_vehicle_model` | Y | 차량 마스터 조회 키 |
| `request_current_soc_percent` | Y | 추천 요청 시점 SOC |
| `request_eta_minutes` | Y | TMAP 실시간 ETA |
| `request_route_distance_km` | Y | TMAP 경로 거리 |
| `arrival_soc_percent` | 파생 | 도착 예상 SOC |
| `soc_risk_level` | 파생 | `SAFE/WARNING/DANGER` |

차량 미등록 시 DA① 문서 기준 fallback 50kWh·4.0km/kWh를 사용하고 `SOC_FALLBACK` 플래그를 남긴다.

---

## 4. 재추천 트리거

| 트리거 | 처리 |
|---|---|
| 가용 수 0대 | 즉시 후보 제외·재랭킹 |
| 가용 수 1대 | 재확인 및 fallback 준비 |
| 상태 경과 15분 초과·미관측 | 확인 필요 표시 |
| 도착 SOC 10% 이하 | 하드필터·재랭킹 |
| 도착 SOC 10~15% | 가까운 다중 충전기 후보 우선 검토 |
| ETA 5분 이상 변화 | SOC 재계산·재랭킹 |
| 새 AWS 스냅샷 도착 | 주 후보 상태 비교 후 트리거 평가 |

외부 공공 API를 사용자 새로고침마다 호출하지 않는다. AWS 루프의 최신 캐시를 사용하고, TMAP은 백엔드가 최종 후보에 요청 시점 호출한다.
