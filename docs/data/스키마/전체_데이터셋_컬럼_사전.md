# 전체 데이터셋 컬럼 사전

| 항목 | 내용 |
|---|---|
| 작성일 | 2026-07-28 |
| 담당 | DA① |
| 범위 | 현재 추천·학습 파이프라인에서 사용하는 원천·정제·패널·라벨·SOC·전달 데이터 |
| 기준 | 저장소의 실제 CSV 헤더와 현재 생성 코드 |
| 제외 | 일회성 요약 JSON·그림·보고서용 집계표, 저장소 밖 BMS 원본 전체 센서 |

이 문서는 실제 컬럼을 찾는 정본이다. 상태 코드의 값은 [`상태코드_매핑.md`](./상태코드_매핑.md), 피처 생성식은 [`피처_카탈로그.md`](./피처_카탈로그.md), HGB 설계는 [`HGB_학습데이터_파이프라인_설계계획서.md`](../../보고/HGB_학습데이터_파이프라인_설계계획서.md)를 함께 본다.

## 1. 공통 규칙

| 표기 | 의미 |
|---|---|
| `statId` / `station_id` | 충전소 ID. 데이터셋에 따라 이름만 다름 |
| `chgerId` | 충전소 내부 충전기 ID |
| `fetchedAt` | 우리 수집기가 API를 조회한 시각 |
| `statUpdDt` | 충전기 또는 운영기관이 상태를 갱신한 시각 |
| `snapshotId` | 상태 수집 회차 ID `YYYYMMDD_HHMMSS` |
| `as_of_ts` / `as_of` / `feature_as_of` | 해당 행의 피처가 알고 있는 기준시각 |
| `null` | 미관측·미조인·판정 불가. 임의로 0으로 바꾸지 않음 |
| `isMock` / `*_is_mock` | 모의 데이터 여부. `true`는 운영 추천에 사용하지 않음 |

시각은 별도 표기가 없으면 KST다. 위도·경도는 WGS84 도 단위다.

### 3.2 S02 충전기 상태 변경분

**기본키:** `snapshotId + statId + chgerId`
같은 키가 페이지 경계에서 중복되면 최신 `statUpdDt`, `pageNo`, 원본 행 순서로 1건을 선택한다.

| 컬럼 | 타입 | 단위·값 | 설명 | null |

## 5. 정제·피처 데이터

### 5.1 D1 충전소 피처 스냅샷

**행 단위:** 충전소 1행
**기준시각:** `as_of_ts`

| 컬럼 | 타입 | 설명 | null·주의 |
|---|---|---|---|
| `statId` | string | 충전소 ID·기본키 | 불가 |
| `as_of_ts` | datetime | 피처 기준시각 | 불가 |
| `statNm` | string | 충전소명 | 가능 |
| `addr` | string | 주소 | 가능 |
| `lat` | float | 위도 | 가능 |
| `lng` | float | 경도 | 가능 |
| `coord_ok` | boolean | 좌표 품질 통과 여부 | false면 공간 피처 제외 |
| `total_chargers` | integer | 마스터 기준 전체 충전기 수 | 0 가능 |
| `available_count` | integer | 관측상 상태 2인 충전기 수 | 미관측과 0 구분 |

## 9. 컬럼 변경 절차

1. 컬럼 추가·삭제·이름·단위·null 의미가 바뀌면 이 문서를 먼저 수정한다.
2. 실제 생성 코드와 샘플 파일 헤더를 함께 변경한다.
3. `schema_version`을 올린다.
4. DA②와 백엔드에 변경 컬럼과 호환성 영향을 전달한다.
5. 기본키 중복, 타입, 필수 컬럼, 미래 누출 검사를 통과한 뒤 전달한다.

M01은 DA① 데이터 핸드오프 v1이며, DA② 승인 전까지 채택 모델이나 운영 추론 계약으로 간주하지 않는다.
