## 5. 갱신·버전 규칙

1. `extracted/`는 타임스탬프 파일명. **덮어쓰지 않고** 최신 1개를 파이프라인이 선택.
2. status **시계열**은 `evaluation/.../SANDBOX_20260717_status_periodic_collection/` 만 사용.
3. 스키마(컬럼 추가·의미 변경) 시 본 사전을 먼저 고치고 수집·가공 담당과 공유.
4. ②(모델)에 넘기는 학습/규칙용 테이블은 **기준시각·행 단위**를 데이터셋 정의서에 별도 명시 (후속).
