# UTIC(경찰청 도시교통정보센터) 개방데이터 요청자 준수사항

| 항목 | 내용 |
|---|---|
| **출처** | [UTIC 개방데이터 신청](https://www.utic.go.kr/guide/newUtisDataWrite.do) 화면 |
| **적용 범위** | EV SafeCharge에서 UTIC **소통·돌발·CCTV·교통안전** 등 개방데이터를 사용할 때 |
| **역할** | AI·데이터 ① (수집·전처리·조인) · 백엔드·프론트(표기) · ②(점수만, 원천 표기는 서비스) |
| **작성** | 2026-07-20 |

> 교통 대체 API 전략: [`주차교통_대체API_전략.md`](./주차교통_대체API_전략.md)

## 1. UTIC가 요구하는 준수사항 (원문 요지)

| # | 내용 |
|---|---|
| **①** | 『경찰청 도시교통정보센터(UTIC)』에서 제공받는 교통정보는 **신청 목적 외 사용 불가** |
| **②** | 『경찰청 도시교통정보센터(UTIC)』**제공 교통정보임을 표기** |
| **③** | 경찰청의 교통정보 제공 **효력은 1년간 유지**되며, 다른 의사표시가 없는 경우 **1년 단위로 연장** |
| **④** | 상기 내용 **미준수 시**, 사실 확인 즉시 **제공 중단** 가능 |

신청 시 「위 내용에 동의합니다」 체크가 **필수**이다.

## 2. 팀 해석 (EV SafeCharge)

### 2.1 ① 목적 외 사용 금지

| 허용 (신청 목적 예시) | 금지 |
|---|---|
| 대구 EV 충전소 추천을 위한 **연구·개발·MVP** | UTIC 데이터를 **다른 상업 서비스·과제**에 재판매·재배포 |
| 충전소 주변 **돌발·소통**을 피처·조인·경고에 사용 | 신청서에 없는 **목적**으로 2차 가공물 공개 |
| 내부 평가·② 모델 입력 | **원본 XML/대량 raw**를 GitHub·외부에 공개 |

**실무**
- UTIC 신청 시 **목적**란을 구체적으로 적는다. (예: 「전기차 충전소 추천 서비스 MVP — 대구 지역 돌발·소통 반영」)
- 목적이 바뀌면 **재신청·합의** 후 사용한다.
- 파이프라인 산출물(D1/D2)에 UTIC raw를 그대로 올리지 않는다. **가공·집계·거리**만 사용.

### 2.2 ② 출처 표기

| 노출 위치 | 표기 예 (팀 합의 후 확정) |
|---|---|
| **앱/웹** (교통·돌발 정보 표시 시) | 「교통정보: 경찰청 도시교통정보센터(UTIC)」 |
| **내부 문서·보고** | 데이터 출처에 `traffic_source=utic` + 본 문장 |
| **②·백엔드 API** | 응답 메타에 `traffic_data_source: "UTIC"` (표기 필드) |

UTIC 별지 「정보출처 표기 예시」(카카오맵·네이버지도 사례)를 참고해 **프론트·백엔드와 문구를 한 번 맞춘다.**

표기 없이 UTIC 데이터만 쓰면 **② 위반**으로 본다.

### 2.3 ③ 1년 효력·연장

| 항목 | 기록 |
|---|---|
| **최초 승인일** | (신청 후 기입) |
| **만료 예정일** | 승인일 + 1년 |
| **연장** | 별도 거절 없으면 1년 단위 자동 연장 — **팀은 만료 30일 전 점검** |
| **담당** | 신청자 / 데이터·파이프라인 담당 |

만료·키 폐기 시 **UTIC 연동 즉시 중단**하고 odcloud·TMAP 등 대체 경로만 사용.

### 2.4 ④ 미준수 시 제공 중단

위 ①~③ 및 UTIC 추가 조건( IP 화이트리스트, 호출 한도 등) 위반 시 **키·연동 중단** 가능.

**대응**
- 위반 소지가 있으면 **즉시 UTIC 호출 중단** → 원인 기록 → UTIC/팀 합의 후 재개
- `.env`의 `UTIC_API_KEY`는 **커밋 금지**
