## 0. 30초 — 단어부터

| 말 | 쉬운 뜻 | 데이터 |
|---|---|---|
| **충전소** | 건물·주차장 **한 곳** (이름·주소·좌표) | `statId`, `statNm` |
| **충전기** | 그 안에 있는 **콘센트 1대** | `chgerId` (같은 소에 1,2,3…) |
| **유형 (`chgerType`)** | 그 콘센트가 **어떤 플러그·속도**인지 | `01`~`10` 코드 |
| **출력 (`output`)** | 대략 **몇 kW**로 밀어 주나 (빠를수록 큼) | 숫자 kW |
| **상태 (`stat`)** | **지금** 비었나/충전 중인가 | `2`=대기, `3`=충전중 … |
| **운영시간 (`useTime`)** | **몇 시까지** 쓸 수 있나 | 문자열 → F08 파서 |

추천 앱에서:

- **급속만 / 완속만** 필터 → `chgerType`(± output)  
- **지금 비었나** → `stat` (관측된 것만)  
- **도착해도 문 열렸나** → `useTime` + ETA  

유형과 상태는 **완전 다른 축**이다.  
“DC콤보인데 고장”도 있고, “AC완속인데 비어 있음”도 있다.

## 1. 급속 vs 완속 (필터용 감각)

| | **완속** | **급속·초급속** |
|---|---|---|
| 느낌 | 집·건물용, **오래** 꽂음 | 고속도로·공공, **짧게** |
| 대표 코드 | `02` AC완속 · `08` DC콤보(완속) | `04` DC콤보 · `01` 차데모 · `06` 멀티 · `10` 초급속 |
| 출력 감 | 대략 **7~22 kW** 근처가 많음 | **50 kW+**, 초급속은 더 큼 |
| 우리 데이터 | 대구 info에서 **`02`가 압도적** | 소수지만 필터·점수에 중요 |

MVP에서 “급속만”을 걸 때는:

- 보통 **`02`·`08`을 빼고** 나머지 DC/초급속을 급속으로 보거나  
- `output`이 있으면 **kW 기준**(예: ≥40)을 같이 쓰는 편이 덜 헷갈림  

(정확한 제품 규칙은 ②·제품이 정함. DA는 코드표·분포만 제공.)

## 2. 플러그가 뭐가 다르나 (이름만)

한국에서 자주 보는 이름:

| 이름 | 한 줄 |
|---|---|
| **AC완속** | 교류 완속. 아파트·건물 충전기에 흔함 |
| **AC3상** | 교류 3상. 완속·중속 쪽 |
| **DC차데모** | 일본계 급속 규격(CHAdeMO). 예전차·일부 차 |
| **DC콤보** | 국내 급속에서 **제일 흔함** (CCS). 요즘 국산·수입 급속 차량 |
| **멀티 (06 등)** | 한 충전기에 **여러 규격**이 달려 있음 → 차종 맞출 확률↑ |
| **초급속** | 아주 높은 kW. 코드 `10` |

차 주인 입장: “내 차가 **콤보만** 되면 `04`·`05`·`06`·`08`·`10` 쪽이 후보.”  
우리가 차종 DB를 안 갖고 있으면, 앱은 **사용자가 급/완·규격을 고르게** 하는 게 MVP.

| `stat` | 쉬운 말 | 추천에서 |
|---|---|---|
| `2` | **비어 있음** (충전 대기) | 가용 |
| `3` | **충전 중** | 사용 중 |

## 5. 자주 헷갈리는 Q&A

**Q. `chgerType=02`인데 `stat=3`이면?**  
A. 완속 충전기가 **지금 충전 중**. 유형(느림)과 상태(사용중)는 같이 본다.

**Q. 충전소 하나인데 유형이 여러 개?**  
A. 정상. 소 안에 완속 3대 + 급속 1대일 수 있음. 행은 **충전기마다** 한 줄.

**Q. `output`이 비어 있으면?**  
A. kW를 추정해서 채우지 않는다(팀 규칙). 유형 코드만으로 급/완 감각을 쓴다.

**Q. `powerType`은?**  
A. API에 있을 수 있는 보조 필드. MVP 핵심은 **`chgerType` + `output` + `stat`**.

**Q. 추천 점수랑 뭐가 연결?**  
A. 유형 자체는 “편의·필터”. **가용·대수·신선도·이동시간·대기위험**이 점수 본체.  
급속만 고르면 **후보 집합이 바뀌는** 쪽.
