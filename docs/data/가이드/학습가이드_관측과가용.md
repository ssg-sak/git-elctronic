# 한눈에 보는 학습서 — 관측·가용·추천이 뭐가 다른가

| 항목 | 내용 |
|---|---|
| **대상** | 비전공·팀원·본인 복습 — “표 숫자가 뭐야?” 할 때 |
| **한 줄** | **상태를 아는 것**과 **비어 있다고 확인된 것**은 다르다. 추천은 그 위에 점수를 얹는 일이다. |
| **역할** | AI·데이터 ①이 재료를 만들고, ②가 “갈 곳”을 고른다 |
| **작성** | 2026-07-20 |

---

## 0. 30초 버전 (이것만 기억)

우리 서비스 목표:

> **가까운 충전소**가 아니라, **가서 꽂을 확률이 높은 충전소**를 빨리 추천한다.

그러려면 최소한 이런 질문이 답해져야 한다.

1. 이 충전기 **상태를 알기나 하나?** → **관측**
2. 안다면, **지금 비어 있나?** → **가용**
3. 그 정보가 **얼마나 신선한가?** → **신뢰도**
4. 그래서 **어디로 보낼까?** → **점수·추천 (②)**

①은 1~3의 **재료**, ②는 4의 **결정**.

---

## 1. 비유로 이해하기 — 주차장 CCTV

충전소를 **대형 주차장**, 충전기를 **주차면**이라고 생각해 보자.

| 현실 | 우리 말 | 데이터에서 |
|---|---|---|
| CCTV가 그 칸을 **한 번도 안 비춤** | **미관측** | `status_missing` / 상태 모름 |
| CCTV가 비춰서 **차 있음/없음**을 봄 | **관측** | status가 있음 |
| 비췄더니 **칸이 비어 있음** | **가용(AVAILABLE)** | `stat = 2` |
| 비췄더니 **차 들어 충전 중** | **사용 중(CHARGING)** | `stat = 3` |
| “비어 있는 칸이 **1개라도** 있는 주차장” | **가용 확인 충전소** | `has_confirmed_available = True` |

중요한 함정:

> **CCTV가 안 보이는 칸 ≠ 차가 있는 칸**  
> 그냥 **모름**이다.  
> 그래서 “미관측을 사용 불가로 넣으면” 추천이 망가진다.

## 2. 표 숫자 해설 (이전 → 지금)

D1을 **예전 한 장짜리 status**로 만들었을 때와,  
**며칠간 15분마다 모은 status**로 다시 만들었을 때의 차이다.

| 지표 | 쉬운 말 | 이전 | 지금 | 해석 |
|---|---|---:|---:|---|
| **관측 충전기** | CCTV가 한 번이라도 비춘 **칸** 수 | ~4% (거의 암흑) | **14,111 / 25,334** | 전체 칸의 약 56%는 “상태를 안다” |
| **평균 관측비율** | 주차장마다 “몇 %의 칸을 아나”의 **평균** | ~0.04 | **~0.56** | 충전소 평균으로도 절반 넘게 상태를 앎 |
| **가용 확인 충전소** | “**지금 빈 칸이 1개 이상**”인 주차장 수 | 219 | **2,645** | “비어 있다고 **확인된**” 곳이 크게 늘음 |

### 자주 하는 오해

| 오해 | 정답 |
|---|---|
| “관측 56%면 절반이 비어 있다” | ❌ 관측 = **안다**. 빈지/찼는지는 별개 |
| “가용 확인 2,645면 그 비율이 충전 성공률” | ❌ 그건 **그 시각에 빈 칸이 있는 충전소 개수** |
| “숫자가 커진 건 AI가 좋아져서” | ❌ **status를 더 모아서** 표가 밝아진 것 |
| “미관측이면 가지 말라” | ❌ 미관측은 **정보 부족**. 고장과 다름 |

## 3. “빈 비율”은 어디에 있나?

특정 충전소에 대해 “얼마나 비어 있나?”에 가까운 숫자는 이것:

| 이름 | 한 줄 뜻 | 비유 |
|---|---|---|
| `availability_ratio_observed` | **관측된** 칸 중에서 빈 칸 비율 | “카메라에 잡힌 칸만” 놓고 빈 비율 |
| `available_count` | 지금 빈 칸 **대수** | 빈 자리 개수 |
| `has_confirmed_available` | 빈 칸이 **1대라도** 있나 (예/아니오) | “빈 자리 있음” 팻말 |
| D2 패널 (시계열) | 시간 지나며 빈 비율이 **어떻게 변하나** | 하루 종일 CCTV 기록 |

“이 충전소는 **평소에** 자주 빈다”는 말은  
→ **한 장의 스냅샷**만으로는 약하고,  
→ **D2처럼 쌓인 기록**이 있어야 한다.

## 4. 우리 목표와 어떻게 연결되나

```text
[① 파이프라인]
  status를 주기적으로 모음
    → 관측이 늘어남 (어둠 → 밝음)
    → 충전소마다 “지금 얼마나 비었나 / 정보는 신선한가” 표로 만듦 (D1)
    → 시간대별 패턴 표로 만듦 (D2)

[② 모델·추천]
  그 표를 보고
    → “갈 확률이 높은 곳”에 점수
    → 사용자에게 Top-N 추천
```

그래서:

- **①이 status를 안 모으면** → 표가 어두움 → ②가 찍어도 근거가 약함  
- **①이 관측·가용·신뢰도를 깨끗이 주면** → ②가 “확률적으로 빈 곳”을 고를 수 있음  

①은 **추천 점수 자체는 안 매긴다.**  
재료가 좋아져야 추천이 좋아진다.

## 5. 미니 퀴즈 (답은 아래)

1. 관측 비율 0.56이면, 충전기의 56%가 비어 있다?  
2. 미관측 충전기는 사용 불가로 세야 한다?  
3. 가용 확인 충전소 수가 늘면, 무조건 추천 품질이 오른 것이다?  
4. “평소에 자주 비는 곳”을 보려면 D1만으로 충분한가?

<details>
<summary>정답</summary>

1. **아니요.** 56%는 “상태를 **안다**”는 비율.  
2. **아니요.** 모름 ≠ 고장/사용중.  
3. **아니요.** status를 **더 보게 된 것**. 점수·추천은 ②.  
4. **아니요.** 패턴은 **시계열(D2)** 이 필요.

</details>

## 7. 한 문장 마무리

> **관측**은 “보인다”, **가용**은 “비어 있다”, **추천**은 “거기 가라”이다.  
> 세 층을 섞어 읽으면 표가 헷갈리고, 나눠 읽으면 목표가 선명해진다.
