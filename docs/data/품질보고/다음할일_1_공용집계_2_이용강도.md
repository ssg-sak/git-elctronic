## 2번 — 이용강도 → D1

### 쉬운 말
대구시 이용현황으로 만든 `적음/보통/많음`을 **충전소 한 줄(D1)** 에 붙인다.  
실시간 “지금 비었나?”를 바꾸지 않는다. **옆에 적어 두는** 것이다.

### D1에 붙는 컬럼 (예)
| 컬럼 | 의미 |
|---|---|
| `usage_level` | 적음/보통/많음 (충전기당 이용강도 삼분위) |
| `sessions_per_charger` | 충전기당 평균 이용 |
| `history_observed` | 이용현황 조인 성공 여부 |
| `usage_weekday_avg` / `usage_weekend_avg` | 평일·주말 평균 (참고) |

여러 타입(급속/완속)이 있으면 **이용강도가 큰 타입** 한 줄을 소 대표로 쓴다.

### ②에게
```text
usage_level은 보조 신호입니다.
실시간 가용·최신성보다 작게 쓰세요.
상태 오래됨/미관측일 때 보정용 합의 부탁.
```

### 실행
```bash
# (필요 시) 이용강도 테이블 갱신
python apps/data-pipeline/processing/features/build_usage_history_features.py
# D1 재빌드 (이용강도 merge 포함)
python apps/data-pipeline/evaluation/personal/experiments/SANDBOX_20260716_preprocess_pipeline/src/preprocessing/build_d1_snapshot.py

```
