## 2. 알아두고 써야 하는 것 (MED)

### M1. 같은 좌표에 충전소 ID가 잔뜩 (에버온 아파트)

예: 성당래미안·복현푸르지오 등 **단지 번호를 소 ID로 쪼갰는데 lat/lng는 단지 대표점 하나**.

- 버그라기보다 **원천 geocode 복붙**
- 지도에 핀이 겹침 · 직선거리 순위가 동일해짐  
- **소 단위 집계·대표점 1개**로 쓰거나, 단지 내 분산은 불가하다고 가정

### M2. `chgerType=11` 미매핑 (5대)

| | |
|---|---|
| 건수 | 5 (충전기) |
| output | **120 kW** → 사실상 초급속 계열로 보임 |
| 코드표 | `CHGER_TYPE_MAP`에 **11 없음** → “알수없음” |

**조치:** 매핑표에 `11` 추가 검토(공식 문서 확인 전엔 `초급속(미확인규격)` 등으로 표기) · 급속 필터에서 누락되지 않게.

### M3. info 안의 `stat` 컬럼 = 실시간 가용 아님

info API가 상태도 실어 옴 (지금 dump: 2가 다수).  
**라이브 가용은 loop1 status만.** info.`stat`로 “지금 빔” 하면 품질 사고.

### M4. `delYn=Y` 787행이 dump에 남아 있음

삭제·제외 표시. **서비스 대상 필터 필수** (`is_service_target` / delYn≠Y).

### M5. useTime 애매·비개방

F08 규칙대로 **UNKNOWN≠열림**, 비개방은 N.
