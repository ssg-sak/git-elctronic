## 5. 한계 (기록용)

1. info가 **1페이지(~1000 / totCnt≈1764)** → 매칭률·realtime 좌표 결합의 상한. **P2(조장 전체 페이지)** 필요.  
2. DB는 **스냅샷** (예: 수집 ~15:26) — 로컬이 실시간 스트림이 아님. 최신화 = re-export → re-join → D1.  
3. 조인 대상 충전소(4,141)와 D1 전체(4,208) 차이: D1은 master 전체 스테이션; 거리만 service 좌표 조인 결과 merge.
