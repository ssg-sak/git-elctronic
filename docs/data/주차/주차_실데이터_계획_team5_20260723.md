| 한다 (①) | 안 한다 |

---

## 1. 왜 mock을 지우나

- 로컬 공공 주차 API는 키 미등록 → 예전에 mock만 둠.
- 조장 공유 DB `team_5`에 **실 PIS**가 이미 있음 (`parking_api_raw`, `parking_realtime_status`).
- mock을 남겨 두면 팀원이 가짜로 점수·조인할 위험 → **삭제**.

## 3. 파이프라인 (① 실행 순서)

```text
[A] team_5 주차 테이블
        │  export_team5_parking_csv.py
        ▼
[B] extracted/parking/*_team5_latest.csv
        │  공간조인 (충전소 service CSV ↔ 주차장 lat/lng, 예: 1km)
        ▼
[C] join_parking_team5_1000m.csv
        │  D1 빌더에 연결
        ▼
[D] station_feature_snapshot
    nearest_parking_m · remaining_spaces · occupancy_rate
    parking_source=team5_pis · parking_is_mock=false
        │
        ▼
    [E] ②·BE 핸드오프 (읽기 전용)
```
