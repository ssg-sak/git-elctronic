| 상태 재확인 필요 | 3,640개 | 오래된 `statUpdDt` 때문에 경고가 필요한 충전소 |

### 관찰

- 공용 충전소는 이용제한·아파트성 충전소와 시간대 패턴이 다르므로, 일반 추천은 공용 후보를 기본으로 봐야 한다.
- 충전기 상태 API는 변경분 중심이다. 한 번 못 받았다고 사용 불가로 바꾸면 안 된다.
- 따라서 화면과 모델은 `available_count`만 보지 말고 **신선도와 미관측 여부**를 같이 써야 한다.

관련 그림: `docs/팀공유/시간대_가용률_20260725/figures/`

## 4. 주차 데이터 EDA·품질

### Team5 realtime 초기 관찰

| 지표 | 값 |
|---|---:|
| realtime 행 | 15,688 |
| 관측 주차장 | 106 |
| 수집 배치 | 148 |
| 평균 점유율 | 43.0% |
| 만차 행 비율 | 11.2% |
| 관측 기간 | 7/23 일부 ~ 7/25 일부 |

낮 시간대로 갈수록 평균 점유율이 높아지는 초기 패턴은 보이지만, 현재는 3일뿐이다.  
따라서 “평소 혼잡 주차장” 점수로 확정하지 않고, 최신 배치의 보조 정보로만 쓴다.

### 충전소가 실제로 있는 주차장 후보

| 등급 | 주차장 수 | 중앙 거리 | 사용 원칙 |
|---|---:|---:|---|
| STRONG | 55 | 12.3m | 검증 후 주차 realtime 보조 정보 후보 |
| LIKELY | 251 | 35.6m | 인근 주차장 정보 |
| NEARBY_ONLY | 238 | 75.2m | 거리만 표시, 점유율을 충전소 상태 근거로 쓰지 않음 |

**핵심 품질 개선:** 기존 1km 매칭은 “근처 주차장”일 뿐이었다.  
이번 등급화로 충전소와 같은 주차장일 가능성이 높은 55개를 따로 볼 수 있게 됐다.

관련 보고서: [`parking_ev_colocation_20260725`](../parking_ev_colocation_20260725/README.md)

## 6. 통합 테스트 결과

대구시청을 가상의 출발 위치로 두고 후보를 추출했다.

```text
전체 4,210
→ 공용 후보
→ 좌표 정상
→ 확정 가용 ≥1
→ 운영중지 제외
= 출력 가능 후보 1,311개
```

그중 상태가 비교적 최근이고 운영 중으로 확인된 **A 후보는 255개**다.

후보별로 아래 근거를 동시에 표시할 수 있었다.

- 공용 여부·이용제한
- 사용 가능/전체 충전기 수
- 상태 신뢰도·운영 여부
- Team5 주차장 거리·잔여면
- UTIC 돌발 거리
- 과거 이용강도
- 충전기 1대, 상태 재확인, 인근 주차장 만차 같은 주의 문구

관련 보고서: [`shadow_recommendation_20260725`](../shadow_recommendation_20260725/README.md)
