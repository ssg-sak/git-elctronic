## 4. 조치

원본 스냅샷은 API 수집 결과 그대로 보존하고, 가공·분석 단계에서 중복을 제거한다.

| 지점 | 조치 | 파일 |
|---|---|---|
| 원본 수집 | 페이지 경계 중복을 포함해 응답 그대로 보존 | `src/collect_status.py` |
| 가공·분석 | dedup 로더로만 다운스트림 공급 | `src/load_snapshots.py` |

`load_snapshots.load_all_snapshots()`는 `(snapshotId, statId, chgerId)` 기준 dedup →
서로 다른 시점의 동일 충전기(=시계열)는 보존하고, 회차 내 중복만 제거한다.

### 조치 후 재검증

```text
rows(deduped): 43160
remaining (snapshotId,statId,chgerId) dups: 0
unique chargers (all time): 10731
20260718_090519  raw 562 -> clean 549 (removed 13)
20260718_093520  raw 559 -> clean 556 (removed 3)
```

> 재검증 시점엔 수집이 계속 진행되어 스냅샷/행 수가 1차 스캔보다 늘어난 상태.
> 핵심은 **읽기 단계 잔여 중복 0** 확인.
