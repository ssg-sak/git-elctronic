## 2. 상세

### 2.1 충전기 상태 커버리지

- info(충전기 row): **25,335**
- status: **593**
- 비율: 593 / 25,335 ≈ **2.34%**
- 원인: `period` 기반 **변경분** 수집 → 전체 스냅샷이 아님

**금지**: 상태 미매칭 충전기를 AVAILABLE=0 / 사용불가로 일괄 처리  
**권장**: `UNKNOWN` / `NO_STATUS` / 관측 여부 플래그 분리 후, 관측분만으로 가용률 산출

### 2.2 status `statNm` 결측

- status 쪽 `statNm`은 **전부 비어 있음**으로 관측
- 복원 키: **`statId` + `chgerId`** → info 조인

### 2.3 좌표 이상 (~27건)

- 주소와 좌표 불일치, 또는 대구 범위(대략 lat 35.6~36.2 / lng 128.3~128.9) 이탈 의심
- cleansing / profiling에서 플래그. 지도·거리 조인 전에 필터

### 2.4 TourAPI 인코딩

- `daegu_tour_attractions_*.csv` 한글 깨짐(모지바케)
- 재추출 시 UTF-8, 또는 Excel/메모장에서 인코딩 확인 후 저장
- 깨진 채로는 관광 POI 밀도 EDA 하지 말 것  
- **대안**: 대구시 관광지 `daegu_city_tour_20260716_232150.csv` (239건) 우선 사용 가능

### 2.5 공원(산책로) 도로명 결측

- `roadNmAddr` 결측률 **81.31%**
- `lotNoAddr`·`lat`/`lot` 존재 → **DROP 금지**
- 분석 시 지번·좌표 기준

### 2.6 주차 mock 실시간 미매칭

- 기본정보 **12** / 실시간 **10**
- 실시간 없는 2곳: 잔여 0·만차로 해석하지 말 것 → **`실시간 정보 없음`**
- `sysgrpyYn=N` 등과 맞춰 피처화

### 2.7 기상 단일 격자

- ultra ncst/fcst, vilage 모두 **nx=89, ny=90** (대구 대표 격자 1곳)
- 문구 예: “대구 중심 격자(nx=89,ny=90) 관측/예보”
- 충전소별 국지 날씨·전역 기상 지도처럼 쓰지 말 것

### 2.8 스냅샷 vs 예측 모델
