## 1. 무엇을 했나

충전소가 **“지금 비는지”** 를 믿으려면, 상태 데이터의 품질과 기준시각이 필요합니다.

저는 팀에서 **분석·품질 점검·지표·대시보드**를 담당했습니다.

- 한 일: 품질 점검, 현황/시간대 지표, EDA, KPI 리포트, 대시보드
- 안 한 일: 추천 점수, Top-N, ML 서빙, 앱 화면

---

## 2. 지표가 만들어지기까지 (짧게)

```
주기 수집 → 품질 점검 → 현황표(기준시각 as_of) / 시간대 표 → KPI·EDA → 대시보드
```

| 항목 | 값 (최종 컷) |
|---|---|
| 현황 기준시각 | 2026-08-09 07:23 (KST) |
| 상태 스냅샷 | 약 2,960개 |
| 품질 검증 | 치명 오류(FAIL) 0 |
| 핵심 지표 | 가용률 · 신선도(갱신 경과) · 시간대/요일 패턴 |

**용어**
- **현황표**: 충전소 1곳 = 1행 (지금 시점)
- **시간대 표**: 충전소 × 시각 (패턴 분석용)
