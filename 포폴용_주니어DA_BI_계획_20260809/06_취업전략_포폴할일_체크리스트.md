## 8. 면접 준비 — 내가 암기할 답

### 8-1. 30초 소개 (프로젝트)

> 전기차 충전소 추천에서 **가까운 순이 아니라 도착했을 때 충전 가능할 가능성**을 보려면, 상태·신선도·시간대 패턴이 필요합니다.  
> 저는 DA①으로 **정의·품질·현재표/시간표·EDA·피처 9개**를 만들었고, 추천 점수는 DA②·백엔드입니다.

### 8-2. 연봉

> 회사 **내규**가 있을 텐데요, 내규가 어떻게 되는지 여쭙고 **내규에 따르겠습니다.** 입사 후 성과 내서 함께 올리고 싶습니다.

### 8-3. 모르는 기술

> 한 번 들어 본 적은 있는데, **대략적으로 알려주시면** 그걸 기준으로 제가 알고 있는 것과 연결해 보겠습니다.

### 8-4. 기술 비교 멘트를 위한 “후보군 +1” (① 범위)

| 말할 때 | +1 후보 | 채택 이유 (한 줄) |
|---|---|---|
| 가용률 집계 | 스냅 단순평균 / 패널 재구성 | **패널(66.4%)** — 편향 통제 |
| ETA | horizon / haversine / tmap | **tmap_eta_min** — 성능 동률·택1·실측 |
| 모델 탐색(HGB) | RandomForest / XGBoost | “**RF·XGB도 후보로 고려**할 수 있으나, 이번 탐색 기준 모델은 **HGB**로 피처 안정성·결측 처리 측면에서 검증했고, **서빙 확정은 ②**” |
| 공백 처리 | ffill 전체 / gap-safe | **>25분 절단** — 가짜 가용 방지 |
| 주차 데이터 | 본선 피처 / HOLD | **HOLD** — realtime 커버 얇음(WARN) |

> 면접 문장 예:  
> “피처 검증을 위해 **HGB를 기준 모델**로 썼고, 트리 계열로는 **RandomForest·XGBoost도 같은 문제에 후보**가 됩니다. 다만 ①의 산출은 **점수 모델 확정이 아니라 피처 9개와 한계(신뢰도 WARN)** 이고, 서빙 모델 선택은 ②입니다.”

### 8-5. 반드시 맞는 질문 카드

| 질문 | 답 위치 |
|---|---|
| 가용률 정의? | 사용가능/(사용가능+사용중) |
| gap-safe? | >25분 세그먼트 절단 |
| FAIL 0인데 WARN? | 폐기 아님 · 한계 고지 |
| 신뢰도 WARN? | 시간블록 B1 · 9개 유지 |
| 최종 피처 9? | 목록 암기 |
| 네 역할 끝? | 점수·Top-N 아님 |
